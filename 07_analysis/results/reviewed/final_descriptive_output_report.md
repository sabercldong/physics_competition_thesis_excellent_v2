# R01 正式描述统计输出说明

输入：`07_analysis/data/final_coding.csv`（SHA-256：`23f76e0c63fad60fa02e54a4b51aeef3e83752da7fb20b46346027aa5a11e045`）

分析单位：219 个独立小问；四个维度各一条记录，共 876 条裁决后编码记录。

本批输出仅为描述性统计。它描述题目任务要求的编码结果，不能推断学生能力、教学效果、长期趋势、因果关系或统计显著性。本批全样本输出不使用分值权重；第35届分值敏感性分析如需使用，须单列为仅本届、E1来源边界下的辅助材料。
