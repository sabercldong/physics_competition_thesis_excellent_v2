# G4-01-NO-RATER-BOUNDARY-PACKET 无真实评分者时的边界路线包

更新时间：2026-07-19

## 性质声明

本文件用于说明在尚未回收真实A/B评分者独立编码表时，`G4-01` 能否继续推进，以及哪些材料可以继续整理。它不替代真实评分者编码、真实一致性检验、分歧裁决、专家审查、人工校对销项或论文正式结果。

## 当前所处位置

项目已经完成三类正式编码前准备：

1. 第35至42届试题已经形成小问级语料和内部试编码底稿；
2. 154项人工校对问题均已建立入口或内部记录；
3. 正式评分者A/B空白模板、裁决模板、评分者说明和交接包已准备。

但正式 `G4-01` 尚未开始。原因是当前没有两名真实评分者分别填写后的 `formal_coding_rater_A_template.csv` 和 `formal_coding_rater_B_template.csv`，也没有真实评分者填写日期、独立性记录、一致性计算结果或裁决记录。

## 当前致命阻塞

1. 真实A/B评分者尚未填写正式模板，因此不能计算评分者一致性；
2. 一致性检验尚未发生，因此不能进入分歧裁决；
3. 裁决后的唯一正式编码数据尚不存在，因此不能生成论文正式统计结果；
4. 154项人工校对虽有入口覆盖，但真实校对人和校对日期均未填写，真实人工销项数仍为0；
5. 第35届8道题分值边界仍缺正式评分细则或真实终核记录；
6. 第42届第3题解答放大图仍缺真实人工终核和附录图号边界确认；
7. 真实专家审查、教师/课堂证据、若干文献全文核验和学校规范仍未完成。

## 可以继续做的工作

在没有真实评分者时，项目仍可以继续做以下内部准备：

| 工作方向 | 可做输出 | 使用边界 |
|---|---|---|
| 证据边界整理 | 正文边界提示、结果章占位说明、主张证据矩阵更新 | 只能写“准备”“候选”“待核验”，不能写正式发现 |
| 材料索引完善 | 评分者交接索引、待核实入口索引、风险路线表 | 只能帮助后续交接，不等于销项 |
| 人工校对准备 | A/B/C/D组待核项的证据页包和回填模板 | 不得代填校对人、日期或最终确认 |
| 文献核验 | 全文访问审计、阅读笔记、引用核验表 | 不得把题录或摘要写成已读全文结论 |
| 学校规范准备 | 模板索取清单、格式风险表、提交门槛表 | 不得预设学校最终格式 |

## 当前不能做的工作

以下工作必须等待真实材料，不得由内部预演替代：

1. 正式双人独立编码；
2. Cohen's kappa、Krippendorff's alpha或任何真实一致性统计；
3. 分歧裁决和正式唯一编码表；
4. 正式总体分布、维度共现、分组比较、趋势结论；
5. 正式案例结论；
6. 教学实验效果、问卷统计、访谈主题或显著性结论；
7. 专家认可、导师确认或学校规范已经满足的表述。

## 路线判断

| 路线 | 当前状态 | 说明 |
|---|---|---|
| 真实评分者路线 | 阻塞 | 需要两名真实评分者独立填写A/B模板后才能继续 |
| 内部边界路线 | 可执行 | 可以继续保护论文草稿不越界，并整理后续交接材料 |
| 人工销项路线 | 条件执行 | 需要真实校对人/日期和终核说明 |
| 教学证据路线 | 阻塞 | 当前没有真实教师、课堂、学生作品或问卷材料 |
| 文献与学校规范路线 | 部分可执行 | 可继续全文核验和规范索取，但不能直接定稿 |
| 正式论文定稿路线 | 阻塞 | 需要正式编码、裁决数据、文献和规范门槛全部满足 |

详见路线表：`07_analysis/results/reviewed/g4_01_no_rater_next_routes.csv`。

## 下一步最小任务

若真实A/B评分者填写表可以回收，则立即回到 `G4-01`，先做回收文件完整性与独立性检查。

若暂时没有真实评分者，则建议执行 `G4-01-NO-RATER-BOUNDARY-APPLY`：检查第3至5章与质量矩阵中是否仍有把内部预演、内部建议或准备材料误写为正式结果的表述，并把它们降格为“内部预演”“候选”“待核验”或“证据需求”。
