# 无真实回填条件下的复现包与正式脚本接口准备链收束

## 性质声明

本文件是 `G1-07-NO-RETURN-FORMAL-SCRIPT-INTERFACE-CLOSEOUT` 的阶段收束报告，用于汇总无真实人工回填条件下已经完成的复现包缺口整理、缺口QA、正式脚本接口检查清单和接口清单QA。本任务只说明哪些材料可以作为未来正式复现需求，哪些动作必须等待真实材料；不修改脚本，不运行正式统计，不生成正式结果表图，不改写论文正文，不修改主张证据矩阵。

## 收束结论

当前准备链可以收束为“未来正式统计复现需求包”，但不能收束为“正式统计已经准备完成”。项目已经明确了正式输入、字段、门禁、脚本接口、输出路径、运行日志、QA和正文使用边界；同时也确认真实人工终核、真实A/B评分者独立编码、分歧裁决和 `07_analysis/data/final_coding.csv` 仍不存在，因此所有第四章正式分布、共现、等级、分组比较、趋势、显著性、p值和效应量继续冻结。

## 当前接口风险

- `present` 字段口径尚未统一：准备版数据字典使用“是/否”，现有描述统计脚本按 `present==1` 处理。
- 正式输出路径尚未统一：脚本当前输出到 `07_analysis/results/generated/`，而正式占位路径登记在 `07_analysis/results/reviewed/final_*.csv`。
- 共现表和分组比较表尚无正式脚本输出接口，不能手工补表。
- 分组比较所需届次、知识模块、情境、表征、数学工具等元数据必须可由 `item_id` 追溯联结。
- 一致性计算脚本只有在真实A/B编码回收后才能产生正式一致性结论。

## 当前不得写入论文的内容

- 不得写认知结构等级正式分布；
- 不得写维度共现、年度变化、知识模块差异或情境差异的正式结论；
- 不得写显著性、p值、效应量、置信区间或统计检验结论；
- 不得把 `internal_coding_v1.csv`、`batch10_*`、`p0_*`、`p1_*` 或 `prep30_*` 输出改名为正式结果；
- 不得声称真实评分者一致性、专家审查、教师验证或课堂验证已经完成。
