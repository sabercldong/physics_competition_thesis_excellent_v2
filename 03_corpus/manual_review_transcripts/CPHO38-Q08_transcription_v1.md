## 题面转写

八、一简化电动汽车模型如图 8a 所示，半径为 `r`、质量均为 `m` 的前轮（两个前轮视为一个物体 `m`）和后轮（两个后轮视为一个物体 `m`）分别视为均质圆柱刚体；刚体车身质量为 `M`，质心位于前后轮轴正中。忽略空气阻力；忽略车轮转动过程中转轴受到的摩擦力矩。

（1）很多电动汽车的发动机是永磁直流电机。在简化模型中，电机动子线圈始终在匀强恒定磁场 `B` 中运动并垂直切割磁力线，切割磁力线的线圈导线总长度为 `l`，转动轨迹的半径为 `r_线圈`，线圈总电阻为 `R_线圈`，线圈自感可忽略。为线圈提供电流的电池的开路电压为 `V`，内阻为 `R_内`。若电机运动部分之间摩擦可忽略，求电机的输出力矩 `tau` 与电机转速 `omega` 之间的关系 `tau(omega)`，最大输出力矩 `tau_max`，输出力矩为零时的最大转速 `omega_max`，以及最大输出功率 `P_max`。为方便此后的计算，将 `tau(omega)` 中涉及的常量用 `tau_max`、`omega_max` 和 `P_max` 表示。

（2）考虑水平地面上汽车从 `t = 0` 时刻的静止状态开始加速的过程，已知在车轮与地面之间不发生滑动的情形下，车身质心在时刻 `t` 的加速度大小 `a` 满足

```text
a = (tau_轮 / r) / (M + 3m)
```

式中，`tau_轮` 是此时车身上的电机向后轮提供的顺时针的力矩。电机和车轮通过变速器连接，假定变速器的机械效率为 100%，电机转速与车轮转速之比（变速比）为 `r_i`。求车速 `v(t)` 与时间 `t` 之间的关系。

（3）利用 A 型汽车的参数数值，以及电机的最大输出功率 `P_max = 2.0 x 10^2 kW`，根据（2）的结果，计算车速从零增加到 `v_f = 100 km/h` 所需的时间。计算这个加速过程消耗的电池能量（以 `kWh` 为单位），以及电池能量转化为机械能的效率。本问可利用的数据和结果：A 型电动汽车的参数 `M = 1.8 x 10^3 kg`，`r = 0.40 m`，`L = 2.9 m`，电机最大输出力矩 `tau = 4.0 x 10^2 N m`，电机转速与车轮转速之比（变速比）`r_i = 10`，车轮质量 `m` 相对于车身质量可忽略。任一半径为 `r`、质量为 `m` 的均质圆柱相对于中心轴的转动惯量为 `J = mr^2/2`。

数值结果保留两位有效数字。
