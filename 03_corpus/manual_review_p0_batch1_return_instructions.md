# P0第一批真实校对回填填写说明

任务编号：`G1-07-FOLLOWUP-MANUAL-P0-BATCH1-RETURN-INSTRUCTIONS`

## 性质声明

本文件用于指导真实校对者填写 `03_corpus/manual_review_p0_batch1_return_template_v1.csv`。它只规定填写规则，不代表真实校对已经发生，不关闭任何人工校对项，不修改题文，不生成正式编码、正式统计、论文正文或 `final_coding.csv`。

## 适用范围

本说明仅适用于P0第一批38个题目级小批次，即第37、38、40、41、42届中同时存在高风险题干OCR项和公式/特殊符号项的题目。

每一行对应一个题目级小批次。填写者需要联合核对题面OCR和答案公式，而不是只看答案或只看转写稿。

## 填写前必须准备

填写任一行前，至少打开并核对：

1. `source_files` 中列出的题目文本文件；
2. `paper_pages` 对应的原题题面页或页面证据图；
3. `solution_pages` 对应的参考答案页或页面证据图；
4. 已有V1转写稿或公式核对表；
5. `affected_item_ids` 对应的分析单元记录。

若上述材料无法定位，不得填写“确认无误”，应填写“继续待核”并说明缺失材料。

## 不要修改的字段

以下字段为继承字段，填写者不得改动：

- `return_id`
- `batch_id`
- `material_id`
- `competition_no`
- `year`
- `question_no`
- `source_queue_ids`
- `source_issue_ids`
- `issue_types`
- `affected_item_ids`
- `source_files`
- `paper_pages`
- `solution_pages`
- `minimum_inputs`
- `must_not_claim`

若发现继承字段本身有错误，不要直接改表，应在 `remaining_uncertainty` 写明，并在 `files_to_update_after_return` 标出需要另行修订的文件。

| `text_revision_needed` | 必填 | `是`、`否`、`待核实` |

| `revision_locations` | 条件必填 | 若任一决定为“需修订”或“继续待核”，必须写具体位置 |

## OCR决定标准

填写 `ocr_decision` 时按以下标准：

- `确认无误`：题干、小问编号、条件、物理量、单位、上下标、特殊符号和文字表达均已与题面页核对，未发现影响理解和编码的错误。
- `需修订`：发现题文、符号、单位、上下标、小问编号或题面条件与原题不一致，且可以指出修订位置。
- `继续待核`：材料缺失、页面不清、符号难辨、图文边界不清，或无法判断当前转写是否正确。

## 公式决定标准

填写 `formula_decision` 时按以下标准：

- `确认无误`：关键答案公式、上下标、正负号、极限、积分/微分、矢量、单位和答案页边界已核对，未发现影响编码证据摘记的问题。
- `需修订`：发现公式、符号、页码范围或答案边界存在明确错误，且可以指出修订位置。
- `继续待核`：答案页不清、公式无法辨认、疑似跨页遗漏、与下一题边界不清，或无法判断当前公式核对表是否完整。

## 正式评分者模板放行判断

`allow_formal_rater_template` 只能在以下条件下填写：

- `允许`：OCR与公式均为“确认无误”，没有剩余疑点，证据摘记足以支持编码者理解题意。
- `不允许`：OCR或公式存在明确错误，或者材料缺失会影响分析单元理解、维度判断或等级判断。
- `暂缓`：存在非致命但尚未解决的疑点，需要下一轮复核后再判断。

只要 `ocr_decision` 或 `formula_decision` 为 `需修订` 或 `继续待核`，`allow_formal_rater_template` 不得填写 `允许`。

## 证据摘记要求

`evidence_note` 不要求长篇解题，但必须说明为什么可以支撑校对决定。建议格式：

`核对题面第X页、答案第Y-Z页；题干中的[关键条件/符号]与原题一致；答案中[关键公式/边界]与核对表一致；未见影响正式编码的文本或公式问题。`

若存在问题，建议格式：

`核对题面第X页时发现[位置]的[符号/单位/文字]与原题不一致；答案第Y页[公式]仍需确认；暂不允许进入正式评分者模板。`

## 整合与提交边界

真实回填后不能直接改为正式结果。必须先完成：

1. 回填副本接收；
2. 校验值记录；
3. 字段完整性检查；
4. 题文或公式修订的单独提交；
5. 回填整合QA；
6. 必要时更新人工校对总清单；
7. 再判断是否允许进入正式评分者模板。

每次提交只能包含当前小批次或当前回填整合任务相关文件，不得混入历史正文、参考文献、主张矩阵或其他脏文件。

## 禁写边界

即使填写说明已完成，仍不得声称：

- P0第一批真实人工校对已完成；
- 38个题目级小批次已经销项；
- 第37、38、40、41、42届题文已经正式无误；
- 正式评分者模板已经可以使用全部P0条目；
- 真实双评分者编码、一致性检验或分歧裁决已经完成；
- `final_coding.csv` 已经生成；
- 第四章正式统计或论文结果已经成立。
