# 试题人工处理说明

任务编号：`G1-07-FOLLOWUP-MANUAL-ITEM-PROCESSING-GUIDE`

## 性质声明

本文件用于说明第35至42届复赛试题进入正式编码前，人工或后续智能体需要对试题材料做哪些处理。它不是论文正文，不生成正式统计，不关闭人工校对项，也不证明真实评分者编码、专家审查、问卷或课堂证据已经完成。

本项目中“处理试题”不是简单整理答案，而是把原始试题、参考解答、图件和元数据转化为可追溯、可复核、可用于正式编码的数据材料。

## 处理对象

人工处理至少覆盖四类材料：

1. 题面材料：题干、条件、选项、小问、图表、单位、符号、页码和题号。
2. 参考解答：解题路径、关键公式、结论边界、答案页范围和与下一题的边界。
3. 图件材料：原题图、裁图、重裁候选图、图注、坐标、箭头、标号和是否混入邻近文字。
4. 元数据与编码材料：届次、年份、题号、小问号、分析单元、知识模块、情境类型、表征形式、数学工具、答案结构、编码证据和待核状态。

## 分析单元拆分原则

当前项目优先以“独立小问”为分析单位。拆分时按以下顺序判断：

1. 若原题明确给出小问编号，原则上一个小问形成一个分析单元。
2. 若一个小问内部包含可独立评分、独立推理或独立建模的任务，应记录为“待核实：是否继续拆分”，不得擅自拆成正式单元。
3. 若多个小问共用同一模型、同一图件或同一连续推导，可保留小问级单元，但在证据摘记中说明共享条件。
4. 若题目没有小问，但参考解答显示存在多个相对独立任务，先保持整题单元，并在待核清单中要求人工判断。
5. 分析单元编号必须能回到原题、题面页和答案页；无法回溯的单元不得进入正式编码。

因此，项目中“219个分析单元”表示当前按题面和小问结构整理出的研究语料单位，不等于“219道题”，也不等于正式结果已经完成。

## 每个分析单元需要人工核对的内容

每条分析单元至少核对以下项目：

| 类别 | 需要核对的内容 | 写入位置 |
|---|---|---|
| 来源定位 | 原始试题文件、参考答案文件、题面页、答案页、下一题边界 | `03_corpus/item_index.csv`、人工校对清单 |
| 题目文本 | 题干是否完整，条件、常量、单位、上下标、特殊符号是否正确 | `03_corpus/item_texts/`、公式核对表 |
| 小问边界 | 小问编号、拆分是否合理、是否存在隐藏子任务 | `03_corpus/item_index.csv`、待核备注 |
| 图件 | 图是否完整，箭头、坐标、图注、编号、比例和裁边是否可靠 | `03_corpus/item_assets/`、图件核对表 |
| 分值 | 大题分值、小问分值、评分细则是否有明示来源 | `03_corpus/item_index.csv`、D组分值队列 |
| 参考解答 | 答案页范围、关键公式和解答步骤是否与该题匹配 | 公式核对表、证据摘记 |
| 内容分类 | 知识模块、二级知识点、情境来源、表征形式、数学工具 | `03_corpus/item_index.csv` |
| 编码证据 | 科学思维维度是否出现、认知要求等级、判定理由 | 正式评分者模板或内部预演表 |
| 风险状态 | 是否仍有OCR、公式、图件、分值或拆分疑点 | `03_corpus/manual_review_checklist.csv` |

## 人工处理和“答案”的关系

参考解答的作用是辅助判断题目要求的物理过程、模型、推理链和关键表征。它不能替代题面，也不能直接成为论文结果。

可以使用参考解答判断：

- 题目是否要求建模、推理、论证或综合迁移；
- 某个小问是否实际包含多个可区分任务；
- 答案页是否完整覆盖该题；
- 公式、符号和结论表达是否被转写正确。

不能用参考解答直接声称：

- 学生真实掌握了某种思维；
- 某题必然属于某一SOLO学习结果层级；
- 某届试题难度显著高于另一届；
- 教学策略已经有效；
- 正式统计结果已经成立。

## 进入正式编码前的最低门槛

一个分析单元进入正式编码前，至少应满足：

1. 题面页和答案页可定位。
2. 题干、小问、公式、单位和特殊符号无未处理高风险错误。
3. 图件若参与理解或论文呈现，已有可核对图件或明确记录为“待重绘/不用于论文图”。
4. 分值若用于统计，必须有明示来源；否则只能写“分值待核实”，不得进入分值统计。
5. 小问边界和分析单元边界能够解释。
6. 编码证据能引用题面或参考解答中的具体任务要求。
7. 待核状态已经明确，不得把“内部预演”“候选图”“待最终复核”写成正式完成。

## 当前仍需人工重点处理的类型

根据现有项目状态，正式编码前仍需重点处理：

1. OCR文本和公式特殊符号终核，尤其是上下标、矢量、希腊字母、积分/微分、极限、不等号和单位。
2. 题图裁边与图注终核，尤其是含坐标、箭头、多子图、图注或邻近文字残留的题目。
3. 第35届分值边界核对，当前多题未见PDF明示分值，不得进入正式分值统计。
4. 第42届第3题题面图与解答放大图边界，不能把参考解答图直接当作题面原图定稿。
5. 小问拆分边界复核，尤其是一个小问包含多步推导、多个模型或多个独立判断的题目。
6. 编码证据摘记复核，确保每条维度和等级判断都有题面或解答依据。

## 给其他智能体的执行要求

后续智能体处理单题或批次时，应按以下格式交付：

1. 处理范围：届次、题号、小问或问题类型。
2. 来源依据：原题文件、答案文件、题面页、答案页、已用候选图或转写表。
3. 核对结论：哪些内容确认无误，哪些仍待核实。
4. 修改位置：实际更新了哪些项目文件。
5. 不放行内容：哪些内容仍不能进入正式编码、统计或论文正文。
6. 证据摘记：足以支撑编码判断的简短题面/解答依据。
7. Git边界：只提交本任务相关文件，不混入历史脏文件。
