# 真实回填等待室更新

## 性质声明

本文件是 `G1-07-RETURN-INTAKE-WAITING-ROOM-UPDATE` 的等待室更新说明。它基于 `03_corpus/manual_review_return_intake_recheck.md` 和 `03_corpus/manual_review_return_intake_recheck_qa.md`，在确认当前仍无真实人工终核回填的前提下，重新划定等待、可安全推进和禁止推进的任务边界。本任务不创建真实回填目录，不填写真实校对人、真实校对日期、校对决定、专家意见、评分者记录、问卷结果、课堂结果或论文正文结论，也不关闭154项待核问题。

## 当前判断

真实人工终核回填仍未到位。四个候选回填目录均不存在；首批A组38行接收登记和剩余B/C/D 78行接收登记均未填写真实接收字段；A/B/C/D四组回填包和154项动作计划中的真实校对人、日期、决定仍为0项填写。

因此，项目不能继续向正式编码、正式统计、第四章正式结果、案例图件定稿、第35届分值统计、第42届第3题附属图边界、主张证据矩阵升级或论文结果章写作推进。等待室的作用是防止项目在没有真实材料时反复检查同一个空状态，同时保留可继续推进的低风险工作。

## 三类任务边界

### 一、必须等待真实回填

以下事项只能等待真实材料，不能由项目助手代填：

- A组76项OCR/公式真实终核；
- B组22项公式与特殊符号真实终核；
- C组47项题图可用性、裁边和重绘决定；
- D组9项第35届分值来源或第42届第3题附属图边界确认；
- 正式A/B评分者编码；
- 真实一致性计算、分歧裁决和 `07_analysis/data/final_coding.csv`；
- 正式结果表、图和运行日志；
- 第四章正式结果写作和主张证据矩阵升级。

### 二、可安全推进

在没有真实回填时，仍可继续推进以下准备工作：

- 维护真实回填接收协议、隔离目录规则、冲突分级和整合QA模板；
- 继续合法文献获取、全文阅读摘记、理论边界核验和主张证据补强；
- 继续学校格式、查重、AI披露、伦理和提交规范登记；
- 维护正式脚本接口需求、字段口径、输出路径和QA清单；
- 维护正文禁写边界、占位说明和证据等级提示；
- 整理其他智能体可执行的缺失材料任务卡。

这些工作只能提高准备度，不能提高正式结果证据等级。

### 三、禁止推进

在真实回填到位前，禁止推进以下动作：

- 创建或伪造 `07_analysis/data/final_coding.csv`；
- 把内部编码、预演结果、候选图或QA表写成正式结果；
- 运行内部数据并命名为正式统计输出；
- 写第四章百分比、趋势、共现、显著性、p值、效应量或置信区间；
- 把内部QA写成真实专家、导师、竞赛教师或评分者意见；
- 升级 `09_quality/claim_evidence_matrix.csv` 中依赖人工终核和正式结果的主张；
- 修改正文来制造已经完成正式研究的效果。

## 后续执行原则

1. 若收到真实回填文件，优先进入接收登记和整合QA，不继续等待室循环；
2. 若没有真实回填，下一步只能选择可安全推进项；
3. 每次推进都必须明确是否依赖真实人工终核；
4. 任何写入论文正文的动作必须先检查证据等级和禁写边界；
5. 正式结果链只在 `final_coding.csv`、正式脚本运行和复现QA均完成后解锁。
