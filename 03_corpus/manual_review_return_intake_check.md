## 正式编码阻断状态

当前正式编码继续阻断，原因不是流程缺少模板，而是缺少真实人工终核回填副本。具体阻断包括：

1. A/B组98项未真实销项，不能进入正式A/B评分者独立编码。
2. 154项整体未关闭，不能生成正式描述统计、分布图表、趋势判断或共现分析。
3. C组47项未确认图件可用性，不能把候选图写成论文最终图、案例图或附录图。
4. D组9项未确认正式分值来源或附属图边界，不能生成第35届分值统计或第42届第3题附属图件定稿。
5. `09_quality/claim_evidence_matrix.csv` 仍需单独任务处理，不能因本检查升级主张证据等级。
6. `08_manuscript/` 正文不得据此写入正式结果、显著性结论、专家审查结论、教师验证或课堂效果。

## 后续接收规则

收到真实回填文件后，必须先执行以下动作：

1. 另存真实回填副本，不覆盖A/B/C/D空白回填包。
2. 建立回收登记，记录来源文件名、回收时间、回收人、组别和副本路径。
3. 按 `03_corpus/manual_review_return_integration_protocol.md` 做结构检查、不可变字段检查、字段完整性检查、证据位置检查和冲突分级。
4. 只有通过整合QA的条目，才可另设任务同步 `manual_review_checklist.csv`、优先队列、销项计划、动作计划、总索引和项目账本。
5. 正文和主张矩阵修改必须另设任务，不能混入回填接收提交。
