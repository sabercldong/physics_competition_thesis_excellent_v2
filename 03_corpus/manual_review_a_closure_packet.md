## 回填表用途

`manual_review_a_closure_packet_v1.csv` 为真实校对人提供以下信息：

| 字段类别 | 用途 |
|---|---|
| 题目信息 | 定位届次、年份、题号、材料ID和受影响小问 |
| 证据入口 | 定位题面页、答案页、V1转写稿、公式核对表和页面渲染文件 |
| 核对重点 | 区分OCR题面文字核对和公式/特殊符号核对 |
| 真实回填栏位 | 留给真实校对人填写代号、日期、决定、是否需修订、修订说明和复核后证据位置 |
| 禁止声称 | 提醒关闭前不得写成正式人工校对完成或正式结果依据 |

## 当前仍未关闭的原因

1. 76项均缺真实校对人或真实校对日期；
2. 当前V1转写稿、公式核对表和页面证据图只能作为复核入口；
3. 若真实校对发现题面、公式、特殊符号或小问边界仍需修订，必须回到对应题目文本或公式核对表另行处理；
4. 关闭前不得把A组材料写成正式编码无风险输入。

## 真实终核建议流程

1. 按 `queue_rank` 顺序处理，优先保持A组原始优先级；
2. 对OCR项，核对题面文字、单位、符号、上下标、分段、小问边界和正式编码证据摘录风险；
3. 对公式项，核对参考解答关键公式、特殊符号、上下标、变量定义和结果式；
4. 在回填表中填写真实校对人/代号、日期、校对决定、是否需修订、修订说明和复核后证据位置；
5. 若决定为“待核实不能关闭”，保留阻塞原因，不得销项；
6. 若决定为“通过无需修订”或“修订后通过”，再更新人工校对主清单和后续正式编码输入版本。
