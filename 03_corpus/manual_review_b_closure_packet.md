## 回填表用途

`manual_review_b_closure_packet_v1.csv` 为真实校对人提供以下信息：

| 字段类别 | 用途 |
|---|---|
| 题目信息 | 定位届次、年份、题号、材料ID和受影响小问 |
| 公式入口 | 定位对应 `*_formula_check_v1.csv` 公式核对表和公式记录数量 |
| 页面证据 | 定位题面页、答案页、边界页和页面渲染文件 |
| 核对重点 | 继承B1批次日志中的逐题真实核对建议 |
| 关联未销项问题 | 提醒同题题图、分值边界或其他人工校对问题仍需另行处理 |
| 真实回填栏位 | 留给真实校对人填写代号、日期、决定、是否需修订、修订说明和复核后证据位置 |
| 禁止声称 | 提醒关闭前不得写成正式人工校对完成或正式结果依据 |

## 当前仍未关闭的原因

1. 22项均缺真实校对人或真实校对日期；
2. 当前公式核对表和页面证据图只能作为复核入口；
3. 第35届8道题另有分值边界问题尚未真实销项；
4. 多道题仍有关联题图问题尚未真实销项；
5. 若真实校对发现公式、符号、变量定义、式号、上下标、边界页或结果式仍需修订，必须回到对应公式核对表另行处理；
6. 关闭前不得把B组材料写成正式编码无风险输入。

## 真实终核建议流程

1. 按 `queue_rank` 顺序处理，保持B组原优先级；
2. 打开公式核对表、题面页、答案页和页面渲染文件；
3. 逐式核对公式、变量、上下标、单位、边界条件、式号和最终结果；
4. 对涉及图像表征或分值边界的题目，只关闭公式问题，不合并关闭题图或分值问题；
5. 在回填表中填写真实校对人/代号、日期、校对决定、是否需修订、修订说明和复核后证据位置；
6. 若决定为“待核实不能关闭”，保留阻塞原因，不得销项；
7. 若决定为“通过无需修订”或“修订后通过”，再更新人工校对主清单和后续正式编码输入版本。
