# 无真实回填语料路径侧车索引

任务编号：`G1-07-NO-RETURN-CORPUS-PATH-QA-LINKAGE-INDEX`

## 性质声明

本索引只为清单 `evidence` 字段未直接附路径的87项人工校对问题提供“问题—回填包—题目文本—页面证据”的只读跳转入口。它不修改 `manual_review_checklist.csv`，也不补写任何人工校对事实。

## 当前结论

87项均能通过A/B回填包反向定位到已存在的核对入口和页面证据：A组76项，B组11项；其中题干OCR38项、公式与特殊符号49项。每项保持“待真实人工终核”和“不放行”。

## 使用方式

1. 用 `issue_id` 在本索引定位对应行；
2. 先打开 `source_file`，确认题目与小问范围；
3. 打开 `primary_review_entry`，阅读已有转写或公式核对入口；
4. 按 `paper_pages`、`solution_pages` 和页面证据路径回到原始PDF逐项人工终核；
5. 只有真实校对者完成终核后，才能按既有回填协议填写校对人、日期、决定和复核后证据位置。

## 边界

- 页面证据路径可达不代表页面内容已经由真实校对者确认；
- 本索引不替代原始PDF、参考解答、真实回填副本或独立QA；
- 不得把索引、转写稿、公式表或渲染图写成正式编码或论文结果证据；
- 87项均不得关闭，除非走完真实回填、接收检查与整合QA。
