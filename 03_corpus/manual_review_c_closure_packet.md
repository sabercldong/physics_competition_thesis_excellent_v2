## 回填表用途

`manual_review_c_closure_packet_v1.csv` 为真实校对人提供以下信息：

| 字段类别 | 用途 |
|---|---|
| 题目信息 | 定位届次、年份、题号、材料ID和受影响小问 |
| 图件入口 | 定位题图复核表、来源页、原裁图、候选图和接触对照图 |

| 真实回填栏位 | 留给真实校对人填写代号、日期、决定、是否可用于论文、是否需重绘、修订说明和最终图件位置 |
| 禁止声称 | 提醒关闭前不得写成正式人工校对完成或正式图件证据 |

## 当前仍未关闭的原因

1. 47项均缺真实校对人或真实校对日期；
2. 当前候选图和内部视觉终检只能作为复核入口；
3. 多数题目仍有同题OCR、公式、分值或附属证据问题未真实销项；
4. 若真实校对发现图号、图注、变量、箭头、边界、分辨率或相邻正文残留仍有问题，必须回到对应候选图或重绘流程另行处理；
5. 关闭前不得把C组材料写成正式论文插图定稿、正式案例图件证据或正式编码无风险输入。

## 真实终核建议流程

1. 按 `queue_rank` 顺序处理，保持C组原优先级；
2. 打开题图复核入口、来源页、原裁图、候选图和对照图；
3. 核对图形主体、箭头、标签、变量、图号、图注、裁边和相邻正文残留；
4. 在回填表中填写真实校对人/代号、日期、校对决定、是否可用于论文、是否需重绘、修订说明和最终图件位置；
5. 若决定为“需重绘”，保存重绘文件、来源说明和不改变题意声明；
6. 若决定为“待核实不能关闭”，保留阻塞原因，不得销项；
7. 若决定为“通过无需修订”或“修订后通过”，再更新人工校对主清单和后续正式编码输入版本。
