# 无真实回填条件下的语料证据路径与页码边界QA

任务编号：`G1-07-NO-RETURN-CORPUS-PATH-QA`

## 性质声明

本审计只检查154项人工校对入口能否通过项目文件路径回到题目整理文本、已登记的页面/转写/公式/图件/分值证据入口，以及题面和答案页码字段是否存在。路径可达不等于原始PDF内容已被重新核对，也不等于真实人工校对、正式编码、统计或论文结果已经完成。

本任务不修改题文、原始PDF、`manual_review_checklist.csv`、真实校对字段、正式编码数据或论文正文。

## QA结论

通过。`manual_review_checklist.csv` 共154项；154项题目整理文本均可定位，题面页与答案页字段均非空。A/B/C/D四组回填包合计154行，与清单 `issue_id` 一一对应；每一行登记的回填包证据路径当前均可定位。

清单自身的 `evidence` 字段只有67项直接写入可解析文件路径，87项仅保留文字说明；这87项通过对应回填包仍能定位到证据入口，不能被误判为材料缺失。直接路径缺失是“清单链接粒度不足”，而不是人工终核完成或未完成的判据。

## 仍然冻结的事项

- 154项均未填写真实校对人和真实校对日期，故真实人工销项仍为0；
- 路径审计不验证页面图像、OCR文字、公式、图注、分值或附属图的内容正确性；
- 不得把文件存在、转写入口、公式核对表、候选图或内部视觉检查写成正式人工终核；

## 发现的可改进点

87项清单的 `evidence` 字段没有直接文件路径，需依靠A/B/C/D回填包反向定位。后续可以建立“清单—回填包—证据入口”侧车索引，降低人工领取时的跳转成本；这项结构补强不改变原清单，更不关闭任何问题。
