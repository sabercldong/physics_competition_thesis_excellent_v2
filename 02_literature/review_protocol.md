# 文献综述协议

## 综述目的

不是证明“没人研究”，而是回答：

1. 科学思维在物理教育中如何定义和测量？
2. SOLO理论如何被使用，它用于试题任务分析有哪些限制？
3. 物理竞赛试题研究通常分析什么，缺少什么？
4. 试题分析如何转化为教学设计？
5. 本研究的分析单位、指标和质量控制从何而来？

## 数据库

待根据学校权限填写，例如中文数据库、学位论文库、英文教育数据库和引用索引。

## 时间范围

- 经典理论文献不设时间下限；
- 经验研究优先近10年；
- 竞赛试题研究可适当扩大范围；
- 所有时间界限需在正文说明。

## 纳入标准

- 与科学思维、物理教育、SOLO、竞赛试题、内容分析或教学转化直接相关；
- 书目信息可核验；
- 至少能获取摘要，核心文献尽量获取全文；
- 研究方法和结论可识别。

## 排除标准

- 仅有宣传性表述；
- 无法核验来源；
- 与论文主张关系弱；
- 重复发表；
- 只凭标题或二手引用无法确认内容。

## 综述结构

1. 科学思维概念与维度；
2. 科学思维测评；
3. SOLO理论及其适用边界；
4. 物理竞赛试题研究；
5. 内容分析与评分一致性；
6. 竞赛教学策略与教学转化；
7. 综合评述与本研究切入点。
