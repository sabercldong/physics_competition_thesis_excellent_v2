# G2-05-PREP 科学思维测评与教学研究综述准备

## 任务定位

本文件启动 `G2-05 完成科学思维测评与教学研究综述`。当前只完成候选来源定位、主题分组和全文阅读要求，不代表已经完成综述，也不能作为第二章正式结论。

本任务服务两个问题：

1. 物理教育和科学教育研究如何测量或分析科学思维、科学推理、科学论证等能力；
2. 这些研究如何约束本论文的写作边界，即试题分析只能说明“任务要求”，不能直接说明学生真实科学思维水平或教学效果。

## 初步综述结构

正式写作时，`科学思维测评与教学研究` 可按以下四个小节组织：

1. 科学思维与科学推理的测评传统：以Lawson测试、科学推理测评和量化模型文献为候选；
2. 物理学习中的科学推理与内容知识关系：比较物理知识掌握、科学推理和问题解决表现之间的边界；
3. 科学论证、模型建构和证据使用的教学研究：为科学论证、模型建构和教学支架设计提供候选依据；
4. 对本研究的约束：本论文分析复赛试题任务要求，不直接测量学生能力；教学转化需要真实教师/课堂证据才能进入效果判断。

## 与本论文四维度的关系

| 本论文维度 | 候选外部文献可能提供的支持 | 当前边界 |
|---|---|---|
| 模型建构 | NGSS科学实践、科学思维模型、物理问题表征研究 | 仍需与中国课程标准中的“模型建构”对齐 |
| 科学推理 | Lawson测试、Bao等科学推理研究、控制变量测评 | 不能把竞赛题中的推理要求等同于学生推理能力 |
| 科学论证 | Osborne等科学论证教学研究、证据论证实践 | 竞赛参考答案中的论证结构不同于课堂互动论证 |
| 质疑创新 | 中文核心素养与质疑能力研究仍需补充 | 英文文献多对应critique、evaluation、nature of science或argumentation，需要谨慎迁移 |

## 需要全文阅读后提取的字段

| 字段 | 填写要求 |
|---|---|
| 研究对象 | 中学生、大学生、教师、课堂、测试任务或课程标准 |
| 学科范围 | 物理 / 普通科学 / 跨学科科学教育 |
| 测评工具或教学干预 | 测试、量表、课堂干预、课程框架或理论模型 |
| 样本与情境 | 年级、国家/地区、样本量、课堂或测试情境 |
| 主要方法 | 测验开发、Rasch/IRT、实验或准实验、课堂话语分析、设计研究等 |
| 可支持主张 | 对应 `C2-02`、`C2-04` 或 `C2-06` |
| 不可迁移之处 | 不能直接用于竞赛试题分析或中国高中物理语境的部分 |

## 可形成的最低判断

在未阅读全文前，只能形成以下工作性判断：

1. 科学思维/科学推理测评已有较成熟的国际候选工具和模型文献；
2. 科学论证和科学实践教学研究可为教学转化提供候选依据；
3. 本研究不能仅凭试题编码推出学生真实能力水平；
4. 本研究不能仅凭教学建议推出教学策略有效。

## 写作边界

- 可以写：这些文献已进入候选清单，待全文核验；
- 可以写：它们提示本研究需要区分任务要求、学生能力和教学效果；
- 不能写：某测评工具已经适用于本研究样本；
- 不能写：某教学方法已经能提升竞赛学生科学思维；
- 不能写：本研究的编码框架已经获得外部测评研究验证；
