## 研究对象与方法

该文的核心对象不是教育测量，也不是物理试题研究，而是大众传播领域内容分析研究中的编码者一致性评估与报告。文章先综述内容分析中intercoder agreement的概念、指标和工具，再对1994-1998年传播学文献中以content analysis为主要方法的200篇研究报告进行内容分析，用来观察该领域如何评估和报告一致性。

作者自己的研究设计包括：

| 项目 | 摘录 |
|---|---|
| 样本 | Communication Abstracts中1994-1998年以content analysis为关键词的研究报告；最终样本200篇 |
| 编码工具 | 先多轮试编码和修订coding instrument，再进行正式pilot reliability test |
| 评分者 | 第二、第三作者对128篇文章进行双人编码，之后各自编码剩余72篇的一半 |
| 一致性指标 | percent agreement、Scott's pi、Cohen's kappa、Krippendorff's alpha |
| 可靠性规则 | 作者以Krippendorff's alpha达到 .70 或 percent agreement达到 .90 作为该研究自身的变量可靠性判定规则 |
| 结果呈现 | 表2逐变量报告不同指标，而不是只报告总体一致性 |

## 对第三章方法设计的直接转化

后续第三章可以据此形成下列方法要求，但必须等真实评分者编码后才能写成正式结果：

1. 正式编码应由至少两名评分者对同一批可靠性样本独立编码。
2. 训练阶段的试编码和正式可靠性检验应分开记录。
3. 对科学思维维度存在性、主要维度、认知结构等级等变量分别报告一致性。
4. 不使用单一总体一致性掩盖具体变量的风险。
5. 若报告percent agreement，应同时报告能处理偶然一致的指标或解释不能报告的原因。
6. 分歧裁决方式必须在方法章说明，并在数据表中保留记录。
