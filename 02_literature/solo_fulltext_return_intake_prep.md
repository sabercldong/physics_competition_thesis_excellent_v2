# G2VE-04 SOLO合法全文回填接收与阅读记录准备

## 性质声明

本文件为 `SOLO-001` 与 `SOLO-002` 在未来获得合法全文或授权副本后建立接收、阅读和边界记录流程。它不表示任何全文已经获得、任何页码已经阅读，或任何理论主张已经获得支持。

本任务不检索或保存非授权全文；不填写真实接收日期、来源、访问渠道、版本、校验值、页码、阅读观察、主张支持状态或引用决定；不修改论文正文、`references.bib` 或主张证据矩阵。

## 当前状态

`SOLO-001` 已完成书目信息定位，尚未获得稳定公开全文；`SOLO-002` 已完成题录和摘要定位，SAGE全文仍需访问权限。两者当前均为“待真实材料”，不得用请求包、题录、摘要或内部推断代替阅读证据。

## 接收后顺序

1. 匹配来源：仅接收与 `SOLO-001` 或 `SOLO-002` 对应的材料，并保留提供渠道和版本定位；来源不明、不能合法使用或与题录不匹配时，停止并登记为冲突或待核实。
2. 固定版本：记录实际获取日期、访问渠道、文件名/馆藏号/数据库页面、校验值或稳定定位；本地文件不进入版本记录前不得进入阅读笔记。
3. 划定阅读范围：记录实际阅读的页码或章节，区分原始层级定义、课程/评价应用、学习结果或任务表现语境，以及与试题分析迁移有关的限制。
4. 形成阅读笔记：只记录必要短摘录或可追溯观察；每条观察必须附实际页码/章节，不得由摘要、二手转述或记忆补齐。
5. 判定边界：单独写明原文能支持什么、不能支持什么；尤其不得把“学习结果/表现”直接转写为“试题本身的SOLO等级”。
6. 连接项目主张：仅将页码级记录作为 `C2-03A/C1-04` 的候选支持材料；必须标注支持、部分支持、不支持、冲突或待核实，不能自动升级主张状态。
7. 独立QA：按 `P1INTAKE-01` 至 `P1INTAKE-10`、`P1INTAKE-14` 至 `P1INTAKE-18` 及 `P1GATE-01/P1GATE-09` 完成接收后QA。QA通过前，正文、主张矩阵和 `references.bib` 继续冻结。

## 冲突与暂停条件

- `C1`：缺少访问渠道、版本、校验值、页码或阅读笔记。保持待核实，不进入主张判断。
- `C2`：全文内容与已定位题录、摘要、既有边界句或候选主张存在实质冲突。冻结相应主张和写作动作，先记录差异。
- `C3`：来源非法、版权许可不清或材料包含不应公开的信息。停止处理，不提交公共仓库，不作引用。

## 放行边界

接收记录完成也不放行正文。只有真实来源、版本/稳定定位、页码或章节、阅读笔记、主张支持判断、冲突处理和禁写边界都通过独立QA后，才能另开“理论写作或矩阵更新”任务。即使进入该任务，也只能使用原文实际支持的有限表述。
