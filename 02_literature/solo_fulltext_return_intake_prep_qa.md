# G2VE-04 SOLO合法全文回填接收准备QA

本QA只检查SOLO全文回填准备流程是否能在未来收到合法材料时保留可复核的接收、阅读和边界记录。通过不表示全文已收到、页码已核验、理论主张已支持，亦不放行第二章、参考文献表或主张矩阵。

## QA结论

通过。接收工作表共2行，覆盖 `SOLO-001` 与 `SOLO-002`；CSV为UTF-8 BOM和LF换行。17个 `actual_` 真实回填字段在两行中均为空。来源、P1回填、P1门禁、接收规则和真实材料到达后的检查任务均已映射。

当前没有发现项目内新增的SOLO全文回填材料。`SOLO-001` 仍为“书目信息已定位且全文未获”，`SOLO-002` 仍为“题录摘要已定位且全文需权限”。

## 已确认的流程边界

- 两篇来源均固定关联 `P1BF-01`、`P1GATE-01`、`P1GATE-09`，并要求执行 `P1INTAKE-01` 至 `P1INTAKE-10`、`P1INTAKE-14` 至 `P1INTAKE-18`；
- 实际材料到达时，下一动作是 `G2VE-04-SOLO-FULLTEXT-RETURN-INTAKE-REAL-CHECK`，不是直接改写论文；
- 真实字段必须由实际获取和阅读材料填充，不得从题录、摘要、请求包或推断复制；
- 即使填写接收表，仍须先完成独立QA，正文、`references.bib` 与主张证据矩阵才可能另开后续任务处理。

## 仍不能声称的事项

- 不能声称任一SOLO全文已取得或阅读全文；
- 不能填入页码、层级定义、应用语境、迁移边界、前结构取舍或主张支持状态；
- 不能声称SOLO适配、L1-L4边界、课程评价迁移或竞赛试题应用已经获得证据支持；
- 不能把本准备QA当作引用许可、文献定稿或理论章节定稿。
