# R01教学设计案例02：状态分类—平均能量关系任务

## 材料性质

这是未实施的竞赛教学设计材料，不是学生分类能力或课堂效果的证据。它以 `CPHO41-Q07-4` 为任务结构参照：该分析单元在当前R01编码中为模型建构L3，逐维题干—解答证据及定位见 `07_analysis/results/formal_rater_r01/r01_case_reselection_evidence_dossier_v1.csv`。实际教学使用前须复核项目登记题面、符号和参考解答版本。

## 适用前提

- 对象：有竞赛物理训练经历且已接触量子态、磁通或能量表达的学习者；实际先备基础必须在实施前单独登记。
- 课时建议：1至2课时，仅作为设计估计。
- 不可作出的推断：本设计不说明学生在奇偶分类、表达式选择或能量比较上存在既定困难，也不证明任何支架有效。

## 对应任务结构与设计目标

| 项目 | 设计内容 |
|---|---|
| 任务结构证据 | 在给定磁通范围和粒子数条件下，组织状态分类并给出单粒子平均能量的变化关系。 |
| R01当前编码 | 模型建构L3、科学推理L1、科学论证L1、质疑创新未出现。 |
| 可观察目标 | 学习者能说明分类依据；能按分支组织可用表达式；能在同一物理量下比较结论并说明分类和能量关系的连接。 |
| 非目标 | 不把完成代入当作模型建构的充分证据，不根据作品给学生贴L1至L4标签。 |

## 任务序列

1. **固定比较对象。** 要求先写清要比较的是何种平均能量、变化量或关系，并列出单位/符号约定。
2. **确定分类依据。** 从题设中抽取粒子数奇偶、磁通区间及前一问可用关系，写入“分类依据卡”；每个分类必须有来自题设的依据。
3. **构建分支表。** 在奇数与偶数、或其他题设要求的分支下分别填写状态条件、可用表达式和计算/推导步骤，不允许只给最终比较结论。
4. **比较与解释。** 把各分支结果放入同一比较表，写出“分类改变了什么条件，因此平均能量关系如何变化”的说明。
5. **反向检查。** 提供一个符号、粒子数或区间改变的相邻情形，要求学习者说明原分支表的哪一列必须改写。
6. **提交产出。** 提交分类依据卡、分支表、比较表、解释段和反向检查记录。真实实施时应保存版本和修改痕迹。

## 支架与撤除

| 阶段 | 可提供支架 | 撤除条件 |
|---|---|---|
| 固定比较对象 | “比较什么物理量？”提示与单位栏 | 学习者能在进入分类前明确比较对象。 |
| 分类依据 | 空白分类依据卡 | 学习者能为每个分支指出题设条件，而不是凭直觉分组。 |
| 分支表 | 三列框架：条件、表达式、推导 | 学习者能自行补充新分支而不遗漏比较对象。 |
| 反向检查 | “哪一条件变化？哪一列必须改写？”提示 | 学习者能独立说明条件变化和表达式/比较关系的连接。 |

## 评价记录（未验证量规）

每项仅记录“可见/部分可见/未见”，并链接到学生作品位置；不形成现阶段论文中的学生分布或效果结论。

| 指标 | 可见证据 |
|---|---|
| 分类依据可追溯 | 每一个分支均能回指题设条件或已给关系。 |
| 分支完整性 | 各分支均包含条件、表达式和推导/计算路径。 |
| 比较一致性 | 比较对象、符号与单位在不同分支之间保持一致。 |
| 关系解释 | 用文字连接“分类条件变化”与“平均能量关系变化”。 |
| 反向检查 | 能指出相邻情形下需要改写的分支和理由。 |
