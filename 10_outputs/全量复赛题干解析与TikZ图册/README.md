# 第35至42届复赛题干、解析与 TikZ 图册

本目录用于制作独立于论文正文的全量附录材料。范围为第35至42届复赛的60道大题；它们在研究数据中被拆为219个小问分析单元。

## 成品要求

每道大题形成一个独立的 LaTeX 源文件，按以下顺序呈现：

1. 整理后的题干与分问；
2. 变量、单位、图号和必要条件的规范数学排版；
3. 参考解答的步骤化转写；
4. 每一幅题图的 TikZ 重绘；
5. 图号、箭头、坐标、关键标注和题设条件的逐项一致性检查。

原始 PDF 页面、裁图和 OCR 文本只作为转写依据，不得嵌入图册或论文正文作为题图。题干、解答和图形只要有一项未完成，就不能把该题标为“完成”。

## 进度文件

运行以下命令刷新60道大题的生产清单：

```bash
python3 build_conversion_manifest.py
```

清单字段明确区分已有题面转写入口、公式核对入口、题图数量和正式图册状态。已有转写入口不等于已经完成正式排版；“TikZ重绘完成”必须对应真实的 `.tex` 图形源和原页一致性核对记录。

## 批次顺序

1. 第37、38、40、41、42届：优先利用已有题面转写和公式核对入口；
2. 第35、36、39届：从原题页与答案页逐题补齐文字和公式；
3. 按每道题的图件清单重绘并逐图核对；
4. 汇总为可编译图册，再进行逐页 PDF 检查。

这套图册是论文的支持性附录材料。论文正文只选择能够直接服务研究结论的典型题目展开，不会把60道大题的完整解答全部堆入第五章。
