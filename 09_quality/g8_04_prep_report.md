# G8-04-PREP：第1至5章术语、编号、交叉引用和格式统一预审

## 任务边界

本轮只检查第1至5章当前草稿中的术语、章节状态、交叉引用和格式一致性，并对明显过时或与前序任务冲突的句子做轻量修订建议。本轮不生成正式统计，不选择正式案例，不补造评分者、专家、教师、学生、问卷、课堂或实验数据。

## 标准术语

| 主题 | 当前统一写法 | 禁止写法 |
|---|---|---|
| 第四章状态 | 正式结果占位与边界说明 | 内部预演结果章、正式结果已经形成 |
| 正式分析文件 | 裁决后的唯一分析表（`final_coding.csv`） | 直接把内部试编码表写成正式分析表 |
| 第五章状态 | 候选材料、待核实分析提纲、采证提纲 | 正式案例结论、教学诊断发现 |
| 教学证据 | 教师/学生/课堂证据需求 | 教师普遍认为、学生主要困难、教学策略显著有效 |
| SOLO等级 | SOLO启发的任务认知结构要求等级 | 学生学习结果等级、试题本身的SOLO层次 |
| 内部材料 | 内部预演、脚本联调、正式编码前准备 | 专家审查、正式评分者数据、正式结果 |

## 主要发现与处理

1. 第一章整体边界清楚，但1.7把后续章节概括为“正式结果、案例机制、教学转化”，与当前第4章和第5章的占位状态不完全一致；本轮已改为“结果占位、案例候选、教学转化证据准备”。
2. 第二章2.6的下一步仍写“建立检索式和数据库记录、核验课程标准”，但这些工作已有阶段性完成；本轮已改为继续补齐SOLO全文、物理竞赛试题研究、其余方法文献和主张证据矩阵闭环。
3. 第三章3.6和3.9仍把第四章描述为“内部预演结果”，与 `G8-03-APPLY-LITE` 后第四章的“正式结果占位与边界说明”不一致；本轮已改为“正式结果占位与证据边界说明”。
4. 第四章当前术语基本一致，已经避免报告具体内部预演数字，仍需在正式结果生成后整体重写。
5. 第五章当前术语基本一致，候选案例、待核实提纲和采证提纲的边界清楚，仍需正式编码、案例证据表和教师/课堂证据后才能升级。
