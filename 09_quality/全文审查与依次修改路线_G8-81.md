# 全文审查与依次修改路线（G8-81）

## 一、审查对象

- 中英文摘要；
- 第一至第六章 Markdown 正文；
- V3 编码手册、221 个分析单元与 884 条唯一编码记录；
- V3 中文统计表、正式图件和六个典型案例；
- 当前 LaTeX 源稿及 76 页 PDF；
- 候选参考文献、引用追溯和华东师范大学专业学位论文公开格式要求。

本次审查只判断当前证据能够支持什么，不重新编码，不补造评分者、专家、教师、学生或课堂资料。

## 二、总判断

当前稿具备完整语料、可追溯编码、稳定描述统计和真实试题案例，可成立为“第 35 至 42 届复赛理论试题的规则约束、作者复核的探索性内容分析”。但在达到“优秀硕士论文”定稿标准前，仍须依次解决编码过程披露、跨编码者可靠性、框架区分效度、分析单位敏感性、案例代表性、讨论深度、引用闭合和学校格式八类问题。

建议结论为“大修后再审”。修改重点不是继续增加正文篇幅，而是提高方法透明度、结论可辩护性和全文可复核性。

## 三、必须优先解决的问题

1. V3 候选记录由 AI 辅助生成，作者在可见候选标签的条件下完成复核；正文须如实披露候选来源、作者可见信息和潜在锚定风险。
2. V3 手册仍标为“重建试编码版”，当前正式结果又缺少身份、训练和互盲过程可核验的独立评分者一致性证据；在补足证据前，不得宣称框架已经获得跨研究者信度或效度验证。
3. 模型建构、科学推理、科学论证和质疑创新的进入门槛不完全对称；四维出现比例只能解释为“在 V3 操作规则下形成的描述性分布”。
4. 科学推理出现率为 100%，模型建构为 91.40%，四维均无 L4；须通过负向对照、边界案例和定义矩阵检验结果是否由规则过宽或等级门槛造成。
5. L4 中的迁移、修正和方案构造与质疑创新维度存在概念重叠；须明确“维度是认知活动类型，等级是该维度内部的结构组织程度”。
6. 60 道大题拆为 221 个分析单元，每题贡献 2 至 9 个单元；须补做分析单元等权、原始小问等权和大题等权的敏感性分析。

## 四、后续修改顺序

### G8-82 理论与方法透明化

- 修订第二、三章和结论中的框架效度措辞；
- 披露 AI 辅助候选、作者非盲复核和 337 行迁移确认；
- 将当前结果统一定位为作者依据 V3 规则形成的探索性描述；
- 建立四维度与 L1 至 L4 的概念矩阵及竞争判定规则；
- 明确参考解答只作必要活动证据，不等于唯一合理解法。

验收条件：正文不再把项目技术 QA 写成独立评分者信度，不再把 V3 写成已经完成外部效度验证的成熟测量工具。

### G8-83 分析单位与稳健性检验

- 为分析单元补充所属大题、原始小问/研究者拆分和拆分理由；
- 生成三种权重口径的敏感性结果；
- 检查第 35 届评分资料敏感性表是否已按 V3 重算；
- 删除或降级因科学推理饱和而退化的 Jaccard 解释。

验收条件：能够说明核心排序和比例是否依赖拆分方式，并将差异如实写入第四章。

### G8-84 讨论与案例重组

- 增加结果讨论，比较既有竞赛研究并分析替代解释；
- 建立 221 个单元到典型案例的选择矩阵；
- 增加质疑创新正例、低等级或维度未出现的对照案例；
- 修复引力案例跨小问混用，补足强激光等案例的关键物理推演；
- 六类结构若不做全样本二次编码，只称“案例中提炼的设计原型”。

验收条件：案例覆盖正例、边界例和反例，不再用六个案例推断全样本中“反复出现”的结构。

### G8-85 教学设计、综述与引文

- 完整展开一份 40 至 45 分钟教学设计；
- 评价量规覆盖物理正确性、关系完整性、理由充分性和边界意识；
- 将未经课堂检验的效果句改为条件式设计语言；
- 增加国内外研究比较表，纳入内容分析方法核心来源；
- 删除或补引正文未使用的参考文献，核准 DOI 和正式引文位置。

验收条件：教学建议是可实施、可观察、待检验的设计方案，参考文献均在正文承担真实论证功能。

### G8-86 学校格式与终稿验收

- 按华东师范大学专业学位论文规范补齐封面、英文封面、声明、授权、摘要、目录、附录和数据可得性说明；
- 修复英文摘要孤页、错误页眉、大面积留白和目录层级；
- 统一题名中的第 35 至 42 届范围；
- 双遍编译并检查页码、图表、公式、引文和交叉引用。

验收条件：形成学校格式 PDF，并保留修改前后版本及编译 QA。

## 五、当前可保留的核心结论

在作者制定并全量复核的 V3 操作规则下，第 35 至 42 届复赛理论试题 221 个分析单元呈现出以模型组织和关系推演为主、显性论证和方案调整任务较少的描述性分布；典型案例据此形成待独立审查和课堂检验的教学设计原型。

该结论不等于框架已经获得跨研究者效度验证，不代表学生能力、教学效果、因果关系、显著性差异或长期命题趋势。
