# V3独立盲评材料包QA（G8-82）

## 一、目的

为补充当前V3作者复核结果的跨研究者可靠性证据，建立不含候选标签、最终标签、统计结果和既有裁决的独立盲评材料包。该材料包只用于真实第二评分者的独立编码，不能由作者本人、项目自动化工具或此前参与编码者代填。

## 二、抽样

- 全样本：221个分析单元、884条四维记录；
- 盲评样本：75个分析单元、300条四维记录，占分析单元总数的33.94%；
- 边界核心：59个分析单元；
- 各届常规补充：第35至42届各2个，共16个分析单元；
- 届次分布：第35至42届分别为6、3、9、7、9、13、16、12个分析单元。

边界核心覆盖全部科学论证正例、全部质疑创新正例、全部模型建构未出现记录和全部科学推理L1记录。抽样分层和V3对照标签仅保存在 `author_only` 目录，不进入评分者交接目录。

## 三、交接内容

评分者只接收：

- `07_analysis/data/v3_independent_validation/handoff_RATER-C/第35至42届V3独立盲评编码表_75单元300行.csv`
- `07_analysis/data/v3_independent_validation/handoff_RATER-C/独立盲评材料索引_75单元.csv`
- `07_analysis/data/v3_independent_validation/handoff_RATER-C/独立盲评操作指令.md`
- `07_analysis/data/v3_independent_validation/handoff_RATER-C/编码规则/`
- `07_analysis/data/v3_independent_validation/handoff_RATER-C/原题与参考解答/`
- `07_analysis/data/v3_independent_validation/handoff_RATER-C/材料包清单与校验值.csv`

不得把 `07_analysis/data/v3_independent_validation/author_only/` 交给评分者。

## 四、程序QA

- 884条唯一编码记录和221个分析单元读取通过；
- 每个分析单元四维覆盖完整；
- 分层并集恰为59个边界单元；
- 各届常规补充恰为16个单元；
- 最终盲评表为75个分析单元、300行；
- 空白模板字段、固定列和行标识校验通过；
- 原题、参考解答、V3手册和决策矩阵均已复制到交接目录；
- 评分者副本不含V3候选标签、最终标签、作者决定或统计结果；
- 对照密钥为300行且只位于作者侧目录。


## 五、回收后的验收

回收后先以 `--mode filled` 检查300行完整性、固定字段、标签逻辑、证据、相邻等级排除、评分者代号和实际日期。结构通过后再由独立比较程序计算：

1. 四维存在性的原始一致率；
2. 各维度Cohen's kappa；稀有类别另报告Gwet's AC1；
3. 出现记录中等级的加权kappa或AC2；
4. 边界核心与各届常规补充样本的分层一致率；
5. 逐条分歧清单和独立裁决记录。

回收前不得预填评分者字段，不得把当前V3标签写入交接材料，也不得在论文中预报一致性结果。
