# G8-02-R01-CITATION-TRACE：六章来源占位追溯（V1）

## 范围与判断

本检查只对六章 Markdown 中出现的来源 ID 进行追溯。它验证来源 ID、已许可的候选参考文献映射和工作版 BibTeX 键之间的对应关系；不验证文献全文质量，不替代学校最终引文格式，也不把待读全文来源升格为正式引用。

## 结果

- 检出的来源 ID 出现次数：50；其中显式 `[引文占位]` 出现次数：44。
- 已进入限边界正式候选的来源 ID：CS-001, METH-004, METH-006, METH-007, ST-002, ST-003, ST-005, ST-006, ST-007, ST-008, ST-009, ST-010, ST-011, ST-012, ST-013, ST-014, ST-015, ST-016, ST-017。
- 这些候选来源的 BibTeX 键均存在：是。
- 仍为待补全文或仅候选的来源 ID：METH-001, METH-002, METH-003。

## 结论边界

1. 当前19项正式候选来源仍只按 `g8_02_bib_lite_mapping.csv` 中的允许范围使用，不能证明编码框架有效、学生能力、教学效果或外部效度。
2. 本轮检出的待补全文或仅候选来源（METH-001, METH-002, METH-003）仅作为待补提示；它们没有被映射为正式候选参考文献。
3. 最终定稿前仍须依据华东师范大学当期规范，把来源 ID 占位替换为统一的正文引文与参考文献表，并逐条复核版本、页码和 DOI/URL 规则。
