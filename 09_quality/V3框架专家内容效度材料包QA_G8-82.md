# V3框架专家内容效度材料包QA（G8-82）

## 一、审查目的

由两名真实专家分别审查V3决策矩阵的20项规则，检查四维定义、存在性门槛、L1至L4边界、维度与等级分离以及物理任务中的可操作性。专家审查与独立盲评编码分开：前者回答规则内容是否清楚、相关和可用，后者回答不同评分者能否得到稳定标签。

## 二、交接材料

目录：`07_analysis/data/v3_framework_expert_review/handoff_EXPERTS/`

- `V3框架专家内容效度审查表_20项.csv`
- `V3框架专家内容效度审查指令.md`
- `科学思维编码手册_V3.md`
- `科学思维编码决策矩阵_V3.csv`
- `材料包清单与校验值.csv`

两名专家须各自复制空白表并独立填写，提交前不得交换逐项评分。

## 三、填写要求

每名专家完成20项记录，每项填写相关性、清晰性、维度—等级分离度和可操作性四个1至4分评分，同时填写接受决定、修改建议、物理例子或反例和独立声明。两人共形成40项专家记录。

## 四、程序QA

- V3决策矩阵读取20项；
- 20项固定字段完整复制；
- 10个专家字段全部留空；
- 模板20/20行校验通过；
- 两名专家的目标文件名和独立声明格式已经写入指令；
- 未预填专家身份、日期、评分或效度结论。

验证命令：

```bash
python3 07_analysis/scripts/validate_v3_framework_expert_review.py --mode template
```

当前结果：

```text
PASS mode=template rows=20
```

## 五、回收后输出

真实回收并通过字段QA后，分别计算四项指标的条目内容效度指数，并报告全表平均内容效度指数；对任一专家评分低于3分或决定为“删除/重建”的规则生成逐项返工表。两名专家的原始意见、规则修订和修订后确认须保留版本对应关系。

未回收前，论文不得写入专家人数、专家评分或“框架已经通过专家效度检验”等结论。
