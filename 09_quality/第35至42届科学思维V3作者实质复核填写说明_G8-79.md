- 题目索引：`07_analysis/results/reviewed/第35至42届V3作者实质复核题目索引.csv`

## 一、复核目的

本复核不是重新抄写候选编码，也不是确认文件结构。作者需要逐题读取题干和参考解答，独立判断每个分析单元在模型建构、科学推理、科学论证、质疑创新四个维度上的存在性与等级，并决定保持、更正或暂缓。

回填表共884行，对应221个分析单元×4个维度。题目索引共221行，用于把同一分析单元的四行放在一起阅读。

## 二、操作顺序

1. 复制空白回填表，命名为 `v3_author_review_<复核代号>_FILLED_<YYYYMMDD>.csv`。不要覆盖空白模板。
2. 先按题目索引的 `item_priority` 处理P0，再处理P1，最后处理P2。
3. 每个分析单元先阅读 `item_text_path` 和 `solution_text_path`，核对 `question_location`、`solution_location`、题干引文和解答引文。
4. 对照V3手册，先判断维度是否出现，再判断L1至L4。不得从候选等级倒推理由。
5. 阅读 `necessary_cognitive_activity`、`decision_reason` 和 `adjacent_level_exclusion`，判断候选理由是否真正得到题干与解答支持。
6. 填完同一分析单元四行后，再进入下一个分析单元。
7. 全部完成后运行成品校验器。只有 `errors=0` 的副本才能进入接收QA。

## 三、优先级含义

| 优先级 | 范围 | 复核重点 |
|---|---|---|
| P0 | 124行，涉及89个分析单元 | 论证/创新正例、模型建构未出现、新增分析单元、同题标签整齐复制、关键词假阳性 |
| P1 | 224行，涉及其余L3边界 | 是否确实存在多关系、多阶段或系统证据，是否应降为L2 |
| P2 | 536行 | 常规存在性、L1/L2和未出现边界 |

P0表示优先复核，不表示候选一定错误；P2也必须逐行完成，不能抽样代替全量回填。

## 四、不可修改字段

从 `review_row_id` 到 `notes` 的全部字段均为只读字段，包括：

- 复核优先级及关联审计；
- item_id、届次、题号、小问号和维度；
- 题干/解答路径、SHA-256、页码、引文和定位；
- 必要认知活动、候选存在性、候选等级；
- 候选理由、相邻等级排除、候选生成信息。

校验器会把这些字段逐行与G8-78候选合并表比较。任何改动都会报错。发现只读字段本身有问题时，在回填字段中选择“待核实”，不要直接改原字段。

## 五、13个回填字段

| 字段 | 允许值或写法 |
|---|---|
| `actual_author_reviewer_or_code` | 实际复核人或匿名代号，不得预填虚构身份 |
| `actual_review_date` | `YYYY-MM-DD` |
| `source_checked` | `是`或`否` |
| `question_evidence_decision` | `充分`、`需补充`、`不可定位` |
| `solution_evidence_decision` | `充分`、`需补充`、`不可定位` |
| `candidate_review_decision` | `保持当前候选`、`更正候选`、`待核实` |
| `rechecked_present_label` | `是`、`否`、`待核实` |
| `rechecked_level` | `L1`、`L2`、`L3`、`L4`、`未出现`、`待核实` |
| `adjacent_level_review` | 从四个固定选项中选择，见下文 |
| `correction_reason` | 保持时写本题针对性理由；更正或待核实时必须说明证据和边界 |
| `post_review_evidence_location` | 写实际核对的题干、解答页或项目路径，不少于8个字符 |
| `reviewer_statement` | 写实际复核声明，不少于12个字符 |
| `author_review_status` | `已完成`、`待补证`、`待裁决` |

`adjacent_level_review` 只允许：

- `认可当前相邻等级排除`
- `修改相邻等级排除（详见更正理由）`
- `维度未出现，不进入等级复核`
- `待核实`

## 六、三种决定的填写逻辑

### 1. 保持当前候选

- `source_checked=是`
- 双侧证据均为`充分`
- 复核后的存在性和等级必须与候选一致
- 维度出现时复核相邻等级；维度未出现时选择“不进入等级复核”
- `author_review_status=已完成`
- `correction_reason`仍须写本题针对性理由，不能只写“同意”或“无问题”

### 2. 更正候选

- 复核后的存在性或等级至少一项与候选不同
- 若判`是`，等级必须为L1至L4
- 若判`否`，等级必须为`未出现`
- `correction_reason`不少于8个字符，说明题干要求、解答证据和相邻等级边界
- `author_review_status=已完成`

### 3. 待核实

- `rechecked_present_label=待核实`
- `rechecked_level=待核实`
- `adjacent_level_review=待核实`
- `author_review_status`只能为`待补证`或`待裁决`
- 在更正理由和证据位置中写清缺什么材料、哪一处不可定位或为什么无法决定

只要题干或解答证据不是“充分”，或者 `source_checked=否`，就必须选择“待核实”，不能选择保持或更正。

## 七、P0专项检查

### 科学论证正例

确认题目是否真的要求围绕一个主张组织证据和理由。普通计算、列方程、长推导、求极值和给出结果不能自动计科学论证。

### 质疑创新正例

确认作答者是否需要自主提出方案、比较替代、修正模型或进行开放构造。前沿情境、出现“任意/提出/设计”等词、解答提供多种方法，均不能单独决定该维度。

### 模型建构未出现

确认本小问是否只调用题目或前问已有模型。如果本小问新增了对象、变量、约束、参考系、等效电路或阶段关系，应考虑更正。

### 同题标签整齐复制

分别写出每个小问独有的必要活动。只有当每个小问都独立满足同一等级标准时，才能保留相同标签。

### 新增分析单元

`CPHO42-Q01-4` 和 `CPHO42-Q04-3` 没有V2历史标签。只能依据原题、参考解答和V3手册判断，不能从相邻小问复制。

## 八、禁止事项

- 不得把AI候选、V2历史编码或跨届审计结论当作作者自己的复核结论；
- 不得使用同一句通用理由批量填充884行；
- 不得只核P0而跳过P1、P2；
- 不得因公式多、答案长、分值高或情境前沿自动判L3/L4；
- 不得为了让分布更好看而增加论证、创新或L4；
- 不得更改只读字段、原题文本或旧V2文件；
- 不得在没有实际逐行核对的情况下填写独立复核声明。

## 九、建议声明

只有在内容与实际过程一致时，复核人可在交付说明中写：

> 我声明：本文件由本人逐题核对题干、参考解答、必要认知活动和相邻等级边界后完成。保持、更正和待核实决定均为本人判断，未将AI候选或他人结论冒充为本人复核结论。

项目不会替复核人预填或验证该声明的真实性，只登记其自述和文件结构。
