# G1-07-CLAIM-MATRIX-P1-OVERLAY-SIDECAR 主张矩阵P1覆盖侧车说明

## 任务结论

本任务生成 `09_quality/g1_07_claim_matrix_p1_overlay_application.csv`，作为7条P1主张矩阵覆盖建议的独立侧车文件。

侧车文件只记录当前矩阵行、拟覆盖边界、拟更新方向和禁止升级要求。本任务没有直接修改 `09_quality/claim_evidence_matrix.csv`。

## 覆盖范围

本轮覆盖7个 `claim_id`：

| claim_id | 当前状态 | 侧车用途 |
| --- | --- | --- |
| C3-01 | 部分准备 | 补充154项人工终核入口齐备但未真实销项的语料边界 |
| C3-02 | 部分准备 | 补充内部预审和A/B空白模板不能替代真实专家或评分者流程的方法边界 |
| C4-01 | 内部预演 | 补充第四章只能占位、内部统计不得写成正式结果的结果边界 |
| C4-02 | 内部预演 | 补充内部复核队列不能替代一致性检验、分歧裁决或稳健性结论的质量边界 |
| C5-01 | 待核验 | 补充候选案例只能作为案例池和复核提纲的案例边界 |
| C5-02 | 缺失 | 补充缺少真实教师、学生或课堂证据时只能写设计建议的教学转化边界 |
| C2-06 | 部分核验 | 补充文献只能支持任务、支架、评价设计参照，不能证明本项目教学效果的边界 |

上述7条在当前工作区的 `09_quality/claim_evidence_matrix.csv` 中均能匹配到现有行。

## 使用规则

侧车文件可以作为后续 `claim_evidence_matrix.csv` 精确合并的依据，但不等同于矩阵已更新。若后续合并，只能考虑补充 `risk` 和 `action` 方向的边界信息，不应改写 `claim`、不应提升 `status`、不应提升 `evidence_level`。

在真实人工终核、真实评分者独立编码、一致性计算、分歧裁决、教师证据或课堂证据形成前，侧车文件不能支持以下说法：

- 正式编码已经完成；
- 正式统计结果已经成立；
- 专家审查、双评分者一致性或分歧裁决已经完成；
- 第四章内部预演数字可以进入摘要、结论或正式结果章；
- 第五章候选案例已经成为正式代表性案例；
- 教师困难、学生困难、课堂可行性或教学效果已经得到验证。

## 后续合并条件

若要把侧车内容合并进 `09_quality/claim_evidence_matrix.csv`，建议另设 `G1-07-CLAIM-MATRIX-P1-OVERLAY-SAFE`，并同时满足：

1. 当前矩阵的历史未提交改动已被隔离、确认或单独提交；
2. 本轮只处理7个目标 `claim_id`；
3. 只补充风险边界和后续动作，不升级主张状态或证据等级；
4. 提交时能证明暂存内容没有混入其他矩阵行或正文改动。
