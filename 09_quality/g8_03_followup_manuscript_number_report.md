# G8-03-FOLLOWUP：第1至5章内部数字句处理建议

## 任务边界

本轮依据 `g8_03_result_reproducibility_gate.csv`，逐章定位第1至5章中仍保留的数字、候选案例、内部预演和结果性句子，并给出正文处理建议。本轮不直接改写第1至5章正文，不生成正式统计，也不制作正式图表。

## 输出

- `09_quality/g8_03_followup_manuscript_number_actions.csv`：40条逐章处理建议。

## 总体判断

第1至3章的大部分数字可以保留，因为它们主要说明语料范围、准备状态、方法流程和正式门槛。第4章虽然已经明确写作“内部预演”，但仍包含大量具体预演数字，正式论文中应改为占位或移入质量说明。第5章的候选案例和教学困难表目前只能作为案例筛选、证据采集或教学设计准备材料，不能作为正式机制结论或教学诊断发现。

## 分章建议

| 章节 | 当前处理建议 | 说明 |
|---|---|---|
| 第一章 | 大体保留 | `219个分析单元`、`154条待核项`和技术路线图可以保留为准备事实，但正式定稿前需按最终语料和校对状态更新。 |
| 第二章 | 保留但维持草案边界 | `L1-L4`、`219个分析单元`等用于理论框架和研究设计图，不得写成正式等级结果。 |
| 第三章 | 保留为方法准备说明 | `219`、`154`、`876`、A/B模板和五项门槛可保留，但不得写成真实评分者编码或正式一致性结果。 |
| 第四章 | 正式稿需大幅收缩 | `219/219`、`147/219`、`7/219`、`592`、`L1-L4计数`、共现数和P0/P1数量不得作为正式结果；建议正式稿只保留结构占位，等待 `final_coding.csv` 后重写。 |
| 第五章 | 改为候选和证据需求 | 6个候选小问、案例机制解释和4类学生困难只能作为候选池或采证提纲；正式稿应在正式裁决后选择2至4个案例。 |

## 优先处理清单

1. 第四章4.2、4.3、4.4中的内部预演数字：正式稿改为图表占位，等待 `final_coding.csv`。
2. 第四章4.6中的P0/P1数量：移入质量控制说明，不作为结果稳健性结论。
3. 第五章5.1候选案例表：正式稿建议移入附录或案例筛选说明。
4. 第五章5.2至5.5机制解释：改为待核实案例分析提纲，补题干、参考解答和正式裁决证据后再进入正文。
5. 第五章5.6教师/学生困难表：无真实材料时移入采证工具准备或删除经验性语气。

## 下一步最小任务

建议执行 `G8-03-APPLY-LITE`：只对第4章和第5章做轻量正文处理，把内部预演数字改为占位或移入“质量控制/候选材料”说明，不动第1至3章已合格的准备事实。若回收真实A/B评分者模板，则优先回到 `G4-01`。
