# 原始三份材料第二版审计

## 总体结论

原始材料可以保留：选题方向、科学思维四维度、试题分析—教学转化主线、部分教学策略想法和答辩章节框架。不能保留：未经核实的年份、比例、显著性、实验结果、专家验证和文献结论。

## 致命风险

### 1. 初稿自带AI生成与使用限制声明

这意味着原文不应被视为已经完成的学术研究，只能作为项目草图。

### 2. 届次与年份疑似错误

初稿表格将第35—42届对应为2020—2027，并出现未来年份。新项目不预填年份，必须根据官方试题核验。

### 3. 比赛阶段英文错误风险

英文摘要把复赛写成 `preliminary round`，与中文题目不一致。最终英文名称必须依据官方表达或可靠译法。

### 4. 结果无数据支撑

初稿中的85%、80%、60%、30%，以及60名学生、前后测均值、t值、p值等，目前均无原始数据和脚本，应全部登记为E0并从新正文删除。

### 5. SOLO理论使用过于直接

初稿把试题直接划为SOLO层次，又把多点结构描述成简单公式调用，理论边界需要重新阅读与论证。优秀版采用“SOLO启发的任务认知结构要求”，并把维度存在性与等级分开编码。

### 6. 框架验证表述没有过程证据

原文称经过专家评审、试用、与得分率和区分度相关，但没有专家表、编码记录、相关数据或统计输出，不能保留。

### 7. 研究范围过大

同时做八届试题、框架开发、问卷、访谈、教学实验和长期人才培养，容易形成方法拼盘。优秀版优先保证语料和编码深度，再按真实条件选择教师或课堂验证。

## 重大风险

- 文献与论述对应关系弱；
- 多篇参考文献格式不完整，需逐条核验；
- 问卷题目和选项截断；
- 问卷缺少量表结构、预测试和基本信息；
- PPT先给出结果，容易反向诱导论文；
- 教学策略多为一般性建议，缺少任务、支架、学生产出和评价量规；
- 结果与讨论混写；
- 语言重复、宏大和模板化。

## 优秀版保留与升级

| 原始想法 | 优秀版处理 |
|---|---|
| 科学思维四维度 | 通过文献、专家和试编码操作化 |
| SOLO理论 | 改为适配任务认知结构的等级并讨论理论边界 |
| 八届试题 | 建立官方小问级语料库 |
| 典型试题 | 用统一案例协议分析机制 |
| 教学策略 | 建立结果—问题—策略—任务—评价链 |
| 问卷 | 先访谈或预测试，重建量表结构 |
| 教学实验 | 有真实条件则改为两轮设计型研究，无则删除因果结论 |
| 答辩PPT | 在正文和结果冻结后重做 |
