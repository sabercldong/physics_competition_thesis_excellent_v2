# R01 六项优先来源公开元数据复核（2026-07-25）

## 目的与范围

本记录只复核当前六项优先来源的公开/官方书目信息、可访问版本入口和既有正文允许用途。它不修改正文，不生成最终文后表，也不把开放仓储副本、作者站PDF、DOI题录或学校公开格式基线升级为最终提交资格。

## 复核结论

六项的题名、作者/机构、年份、期刊或出版物定位、DOI/官方入口均与当前候选条目一致：`CS-001`来自教育部通知与附件包；`ST-002`、`ST-003`、`ST-005`和`METH-004`以DOI内容协商返回的登记元数据复核，其中`ST-005`另由Wiley页面复核；`ST-006`以National Academies Press入口和DOI登记复核。

`ST-003`的DOI登记显示出版版本为CC BY 4.0；其余来源的可读副本、仓储版本或特定补充材料仍必须按各自边界处理。逐条明细见`r01_p0_reference_metadata_recheck_20260725.csv`。

## 仍不放行的事项

1. 六项均为“最终参考文献就绪：否”。当前学校公开基线并不替代作者实际答辩期的学院规则。
2. 不引用未单独定位的`ST-002`补充材料、`ST-003`图表或`ST-005`仓储版与VOR之间尚未逐页核对的内容。
3. `METH-004`可支持报告方式的边界，不能给本项目设定唯一阈值或证明人工过程已经完成。
4. `CS-001`与`ST-006`是课程/框架依据，不能证明编码框架外部效度、学生能力或教学效果。

## 可复核入口

- 教育部课程标准通知：[官方通知页](http://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)；项目内定位见`02_literature/reference_verification.csv`。
- `ST-002`：[DOI](https://doi.org/10.1126/science.1167740)。
- `ST-003`：[DOI](https://doi.org/10.1103/PhysRevPhysEducRes.18.010115)。
- `ST-005`：[DOI](https://doi.org/10.1002/tea.20035)。
- `ST-006`：[DOI](https://doi.org/10.17226/18290)。
- `METH-004`：[DOI](https://doi.org/10.1111/j.1468-2958.2002.tb00826.x)。
