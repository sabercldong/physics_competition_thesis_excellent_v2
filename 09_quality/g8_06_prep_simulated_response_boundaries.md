# G8-06-PREP：模拟答辩与高风险问题清单准备版

## 任务边界

本文件只是答辩风险准备材料，不代表已经进行了真实答辩、模拟答辩、导师审查或专家审查。

本轮不生成答辩结论，不评价论文是否已经达到提交要求，不补造导师意见、专家意见、评分者数据、教师访谈、问卷、课堂记录、学生作品、实验数据、显著性结果或参考文献结论。

## 总体判断

当前项目已经形成较完整的研究材料包和第1至5章边界版草稿，但还不是最终提交版论文。答辩或预答辩中最容易被追问的不是文字表达，而是以下六类证据边界：

1. 内部预演结果不能替代正式双评分者编码；
2. 没有 `final_coding.csv` 时不能报告第四章正式结果；
3. 没有教师、学生或课堂材料时不能证明教学策略有效；
4. SOLO理论只能作为任务认知结构要求的启发性框架，不能直接等同于学生学习结果；
5. 文献综述仍有全文缺口，研究空白只能写成候选判断；
6. 学校格式、匿名评审和AI披露规则未取得，最终版还不能封关。

## 可使用的回答边界

### 1. 关于为什么重建论文

可以回答：原初稿保留选题方向和科学思维四维度线索，但年份、试题统计、问卷、教学实验、显著性结果和参考文献不能直接继承。新版项目改为从语料、编码、文献和证据矩阵重新建立研究链。

不能回答：原初稿中的调查、实验、显著性结论或专家验证已经被确认。

### 2. 关于研究对象

可以回答：当前已经建立第35至42届复赛试题的小问级语料索引，共219个分析单元。这一数字可用于说明语料库规模。

不能回答：219个分析单元已经产生正式科学思维分布结果。正式结果必须等待真实评分者编码、分歧裁决和裁决后的唯一分析表。

### 3. 关于编码框架

可以回答：当前已形成正式草案、内部版手册、训练材料、A/B评分者模板、裁决模板和一致性计算脚本，说明编码流程已经准备到交接阶段。

不能回答：编码框架已经通过真实专家审查、真实评分者试用或正式一致性检验。

### 4. 关于SOLO理论

可以回答：本研究采用“SOLO启发的任务认知结构要求等级”，分析的是试题任务要求，不直接测量学生真实学习结果。

不能回答：某道题本身就是学生SOLO学习结果层级，也不能把SOLO等级简单等同于题目难度、综合性或创新性。

### 5. 关于第四章结果

可以回答：第四章目前保留结果结构、正式输出门槛和边界说明，等待 `final_coding.csv` 后重写。

不能回答：内部预演中的维度比例、等级比例、共现数、分组比较或趋势就是正式结果。

### 6. 关于第五章教学转化

可以回答：第五章目前可以作为案例候选、证据采集提纲和教学转化设计入口。若没有真实教师或课堂证据，最稳妥写法是“设计建议与证据需求”。

不能回答：教师普遍认同、学生主要困难已经被调查发现、教学策略已经显著提升学生科学思维。

## 高风险追问优先级

| 优先级 | 问题类型 | 当前最佳处理 |
|---|---|---|
| P0 | 真实评分者编码在哪里 | 承认尚未发生，展示A/B模板、交接包和一致性脚本 |
| P0 | `final_coding.csv`在哪里 | 承认未生成，第四章保持占位 |
| P0 | 教学策略是否有效 | 承认不能证明有效，只能写设计逻辑或证据需求 |
| P0 | 为什么不用初稿显著性结果 | 说明原始数据和脚本缺失，按E0清除 |
| P1 | SOLO是否理论错用 | 使用“任务认知结构要求”边界表述 |
| P1 | 文献综述是否完整 | 说明部分核验，全文缺口仍在 |
| P1 | 创新点是否过大 | 收束为已完成材料和待完成条件 |
| P2 | 格式是否可提交 | 等学校模板和AI披露规则后再封关 |

## 下一步衔接

若要让这些问题从“风险准备”转成“可答材料”，最小推进顺序是：

1. 销项 `03_corpus/manual_review_checklist.csv` 中影响正式编码的高风险条目；

3. 完成分歧裁决并生成 `final_coding.csv`；
4. 用脚本重算第四章正式表图；
5. 决定第五章是收缩为设计建议，还是补真实教师/课堂证据；
6. 补齐SOLO、物理竞赛试题研究和方法文献全文；
7. 获取学校格式、匿名评审和AI披露规则后执行格式封关。

在上述任务完成前，本材料只能作为高风险问题清单和准备稿，不能写成“模拟答辩已经完成”或“论文已具备提交条件”。
