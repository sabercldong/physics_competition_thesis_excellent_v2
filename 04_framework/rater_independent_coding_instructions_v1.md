# 评分者A/B独立填写说明

更新时间：2026-07-14

## 使用边界

本说明用于评分者A/B独立填写空白编码模板。当前尚未完成真实双评分者编码、分歧裁决或一致性检验；任何已填模板在通过回收检查前都不能进入论文正式结果。

## 独立性要求

1. 评分者A只填写 `formal_coding_rater_A_template.csv`；
2. 评分者B只填写 `formal_coding_rater_B_template.csv`；
3. 两名评分者在提交前不得互看对方模板；
4. 两名评分者不得参考Codex内部试编码、内部预演统计、P0/P1建议或典型案例候选结论；
5. 遇到不确定记录时，只在本人的 `notes` 中写明原因，不与另一名评分者协商统一。

## 判断依据

评分者只能使用以下材料作为编码依据：

- 原始题面；
- 参考解答；
- 题图、表格、图注；
- 交接包中的分析单位定义、维度定义、等级定义和证据摘记规则。

不得使用以下材料作为编码依据：

- 内部预演结果；
- 模拟评分者结果；
- 未核验的初稿结论；
- 未读全文文献中的结论；
- 教师、学生、专家意见的假设性表述。

## 字段填写规则

| 字段 | 填写规则 |
|---|---|
| `present` | 只填“是”或“否”。若该维度未出现，填“否”。 |
| `level` | 维度出现时填 `L1`、`L2`、`L3` 或 `L4`；维度未出现时填“未出现”。 |
| `evidence` | 必须写可定位证据，说明依据来自题干、解答、图表或图注。 |
| `confidence` | 只填“高”“中”“低”。材料存在疑问或边界模糊时，不得填“高”。 |
| `coder_id` | 使用评分者代号，不写真实姓名。 |
| `coding_date` | 使用 `YYYY-MM-DD`。 |
| `manual_version` | 填写本次交接使用的手册版本或冻结编号。 |
| `notes` | 记录待核实、OCR疑问、公式疑问、图题疑问、小问边界疑问或其他理由。 |

## 待核实处理

如果某条记录涉及 `03_corpus/manual_review_checklist.csv` 或 `prep30_manual_priority_queue.csv` 中的未销项问题，评分者应：

1. 先按可见材料作保守判断；
2. 在 `notes` 中写“待核实：”并说明疑点；
3. 若疑点直接影响维度存在性或等级，不得填“高”把握度；
4. 不自行补写题干、公式、图注或答案内容。

## 提交前自查

提交前请确认：

- 876条记录均未增删；
- 每条记录均完成 `present`、`level`、`evidence`、`confidence`、`coder_id`、`coding_date`、`manual_version`；
- 所有“待核实”均写入 `notes`；
- 文件按 `rater_handoff_file_rules.csv` 命名；
- 未复制内部预演或训练案例结论。
