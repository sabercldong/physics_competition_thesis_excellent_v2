# 专家审查材料包

更新时间：2026-07-14

## 目的

本材料包用于 `G3-05` 专家审查，目标是让外部专家评价“科学思维维度—SOLO启发的认知结构要求等级”编码框架是否适合分析第35—42届复赛试题。

本材料包不包含任何已完成的专家意见。所有专家评分、建议和修改决策必须在真实审查发生后另行记录。

## 审查对象

1. `04_framework/theoretical_framework.md`：理论对象、四维度和SOLO适配边界；
2. `04_framework/coding_manual_v1.md`：分析单位、维度定义、纳入排除规则和等级草案；
3. `04_framework/codebook.csv`：16个维度-等级指标的结构化表；
4. `04_framework/expert_review_sample_items.csv`：覆盖第35—42届的24个样本小问；
5. `04_framework/expert_sample_item_review_form.csv`：样本小问编码审查表。

## 样本说明

样本小问采用目的性抽样而非随机抽样：每届选取3个小问，共24个样本。抽样优先覆盖高阶L4判定、科学论证边界、不同知识模块和仍有人工校对风险的题项。它的用途是暴露编码手册的边界问题，不用于估计总体分布。

正式编码一致性检验仍需按 `04_framework/reliability_plan.md` 另行抽样和计算，不能用本专家审查样本替代。

## 审查问题

专家审查重点回答五个问题：

1. 四个科学思维维度的定义是否清晰、可观察、适合竞赛试题分析；
2. L1-L4等级是否能区分不同认知结构要求，而不是只反映计算复杂度；
3. 纳入规则和排除规则是否能减少评分者随意判断；
4. 样本小问的试编码是否暴露出定义不清、等级过高或维度误判；
5. 框架是否存在理论风险，尤其是把SOLO从学习结果迁移到试题任务分析时的边界。

## 专家填写文件

- `04_framework/expert_panel_template.csv`：专家背景与审查进度登记，不填写真实姓名，可使用E01、E02等编号；
- `04_framework/expert_indicator_review_form.csv`：逐指标评分与意见；
- `04_framework/expert_sample_item_review_form.csv`：样本小问编码意见；
- `04_framework/expert_review_log.csv`：真实反馈回收后，用于记录修订决策和版本变化。

## 评分规则

指标审查采用4级评分，避免中性选项：

- 1：不适合，需要删除或重写；
- 2：问题较多，需要较大修改；
- 3：基本可用，需要小修；
- 4：清晰可用，可以保留。

五个评分栏分别为：

- `relevance_1_4`：与科学思维维度是否相关；
- `clarity_1_4`：表述是否清晰；
- `observability_1_4`：是否能从题干和解答中观察判断；
- `distinctiveness_1_4`：与相邻等级或相邻维度是否可区分；
- `applicability_1_4`：是否适合第35—42届复赛试题。

## 回收后处理

真实专家意见回收后，应完成以下步骤：

1. 隐去专家身份信息，仅保留专家编号和必要背景；
2. 将评分与开放意见录入 `expert_review_log.csv`；
3. 对每条意见标记 `保留`、`小修`、`大修`、`删除` 或 `待导师确认`；
4. 在 `coding_manual_v2.md` 中体现采纳的修改；
5. 未采纳意见必须记录理由；
6. 在进入双人试编码前冻结修订后的手册版本。

## 当前边界

- 若专家指出理论框架不适配，应先修订手册，再进入评分者一致性流程。
