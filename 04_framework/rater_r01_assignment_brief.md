# G4-02 R01后双评分者独立编码领取指令

需要两名不同的真实人员，分别使用匿名代号`RATER-A`与`RATER-B`，独立完成编码。提交前不得互看、讨论或合并模板。

## 评分者A

1. 复制 `07_analysis/data/formal_coding_rater_A_template.csv`。
2. 填写全部876行的`present`、`level`、`evidence`、`confidence`、`coder_id`、`coding_date`、`manual_version`和`notes`。
3. `coder_id`填`RATER-A`；`manual_version`填`G4-01-R01-2026-07-22`。
4. 命名为 `formal_coding_rater_A_FILLED_YYYYMMDD.csv`，交至项目负责人。

## 评分者B

1. 复制 `07_analysis/data/formal_coding_rater_B_template.csv`。
2. 按与A完全相同的字段规则独立填写。
3. `coder_id`填`RATER-B`；`manual_version`填`G4-01-R01-2026-07-22`。
4. 命名为 `formal_coding_rater_B_FILLED_YYYYMMDD.csv`，交至项目负责人。
