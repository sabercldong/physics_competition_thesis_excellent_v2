# G3-04-DRAFT 证据摘记与分歧记录协议

更新时间：2026-07-14

> 状态：正式草案配套协议。本文只规定评分者如何写证据、如何记录分歧和何时停止裁决，不代表已经完成真实评分者编码、分歧裁决或一致性检验。

## 一、证据摘记最低格式

每条 `evidence` 建议采用以下结构：

```text
来源类型：题干/参考解答/题图；
定位：届次-题号-小问-页码或整理文本位置；
证据内容：摘记能支撑判断的条件、步骤或图示；
解释：说明该证据为何触发某维度或某等级；
相邻边界：说明为什么不是更低或更高等级；
疑点：OCR/公式/题图/小问边界/手册定义是否待核实。
```

若模板字段空间有限，可压缩为：

```text
题干/解答页X：证据摘记；触发维度/等级理由；相邻等级边界；待核实项。
```

## 二、可接受证据

| 证据来源 | 可用于 | 注意事项 |
|---|---|---|
| 题干明确要求 | 维度存在性、等级判断、质疑创新触发 | 优先级最高，应尽量摘原题关键词或任务要求。 |
| 参考解答必要步骤 | 判断完成任务所需的模型、推理或论证结构 | 只能使用完成该小问必需步骤，不能用可替代解法任意升等。 |
| 题图或图表 | 判断表征、边界条件、模型对象和推理约束 | 图像未校对时标待核实。 |
| 研究者替代解法 | 只作边界讨论 | 不得单独触发维度或提高等级。 |

## 三、不可接受证据

- “这题很难”；
- “公式很多”；
- “背景很新”；
- “解答很长”；
- “我觉得需要创新”；
- “Codex 内部编码为 L4”；
- “PPT/初稿中说该类题占比较高”；
- 没有页码、题号或解答步骤的笼统判断。

## 四、把握度规则

| 把握度 | 判定条件 | 后续处理 |
|---|---|---|
| 高 | 题干或参考解答证据清楚，相邻等级边界清楚，材料无明显校对风险。 | 可进入一致性计算。 |
| 中 | 证据基本清楚，但相邻等级仍可能分歧，或材料有轻微待核。 | 进入分歧讨论重点样本。 |
| 低 | 证据不充分、材料未校对、分析单位不稳或手册定义不清。 | 不宜直接裁决；优先补证据或修订手册。 |

## 五、分歧类型

| 分歧类型 | 定义 | 处理顺序 |
|---|---|---|
| 存在性分歧 | A/B 对同一维度是否出现判断不同。 | 回到题干和参考解答证据，先判断是否有任务要求。 |
| 等级分歧 | A/B 均判出现，但 L1-L4 不同。 | 对照相邻等级定义，重点检查是否误把复杂计算当高阶。 |
| 证据分歧 | A/B 结论相同，但证据依据不同。 | 保留更可定位、更符合证据优先级的证据。 |
| 材料分歧 | 一方或双方因 OCR、公式、图像、小问边界标待核实。 | 先完成材料校对，再讨论维度和等级。 |
| 手册分歧 | 分歧来自定义不清或边界案例不足。 | 记录需修订条款，修订后重新编码相关样本。 |

## 六、裁决记录最低格式

裁决记录应包含：

- 分歧记录编号；
- `item_id`；
- `dimension`；
- A/B 原判断；
- 分歧类型；
- 裁决后 `adjudicated_present`；
- 裁决后 `adjudicated_level`；
- 裁决证据；
- 裁决理由；
- 是否需要修订手册；
- 是否仍为待核实。

若材料未校对，裁决结果应写为“待核实”，不得为了形成完整数据表而强行给出等级。

## 七、正式统计入口规则

只有满足以下条件的记录，才可进入正式唯一分析表：

1. 题干、参考解答和题图无影响判断的待核实问题；
2. A/B 两名评分者独立编码已完成；
3. 分歧已记录并裁决；
4. 裁决证据可定位；
5. 使用的编码手册版本已明确；
6. 该记录未被标为材料待核实或手册待修订。

不满足以上条件的记录只能进入准备表、复核表或问题清单，不能进入论文正式结果。

## 八、正文写作边界

正式论文方法章可以在完成真实试编码后描述本协议的使用方式。当前阶段不得写：

- “两名评分者已根据本协议完成独立编码”；
- “分歧均已裁决”；
- “一致性达到预期标准”；
- “本协议证明编码框架有效”。

当前只能写为：

> 项目已形成评分者证据摘记与分歧记录协议草案，后续将用于真实评分者试编码和正式编码过程。
