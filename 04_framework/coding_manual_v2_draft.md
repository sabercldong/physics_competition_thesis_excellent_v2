# 编码手册V2草案

> 状态：内部预审后草案。尚未经过真实专家审查、导师确认或评分者一致性检验，不得作为正式编码冻结版。

## 一、分析对象

本研究分析的是复赛试题对解题者提出的认知活动要求，而不是学生实际表现出的科学思维水平。所有等级均表示“任务认知结构要求”，不得写成学生能力等级或学习结果等级。

## 二、分析单位

- 默认单位：独立小问；
- 若一个小问内部包含互相独立的任务，可拆为更小分析单元；
- 若多个小问共享题干背景，背景信息作为整题元数据，小问要求分别编码；
- 分析单位拆分必须能回到原题题号、小问号、题面页码和参考解答页码；
- 第40届等已细分条目在正式编码前需再次人工复核拆分边界。

## 三、证据优先级

维度存在性和等级判定按以下证据优先级处理：

1. 题干明确要求；
2. 完成该小问所必需的参考解答步骤；
3. 题目给出的图表、条件、边界或实验情境；
4. 研究者可想到的替代解法。

第4类只能作为辅助讨论，不能单独触发维度或提高等级。

## 四、通用排除规则

以下情况不自动触发高阶编码：

- 计算步骤长；
- 公式复杂；
- 背景前沿或陌生；
- 题目涉及多个物理量；
- 需要画图或读图；
- 参考解答篇幅较长；
- 研究者能想到更高级的解法，但题目并不要求。

## 五、维度定义与等级

### 1. 模型建构

定义：从题设情境中确定研究对象、系统边界、变量、理想化假设和物理关系，并形成支持求解的模型。

纳入：

- 需要选择研究对象或系统边界；
- 需要识别可忽略因素或适用条件；
- 需要将情境映射到物理模型；
- 需要修正、组合、迁移或一般化模型。

排除：

- 题干已完整给出模型、方程和假设，只需代入；
- 仅整理符号或机械画常规受力图；
- 只因背景新颖而无模型选择。

等级：

- L1：直接识别单一标准模型；
- L2：并列识别多个对象、变量或子模型；
- L3：整合多个过程、边界和假设形成统一模型；
- L4：在陌生或扩展情境中迁移、修正、一般化或构造模型。

### 2. 科学推理

定义：依据物理规律、题设条件和数学关系，建立从条件到结论的逻辑链。

纳入：

- 多步因果推演；
- 守恒量选择；
- 临界条件或边界条件判断；
- 数学表达与物理意义转换；
- 参数化、递推、极限或优化推导。

排除：

- 单步代入；
- 与物理意义无关的机械代数；
- 只抄写题干公式。

等级：

- L1：单一关系直接推断；
- L2：多个关系并列使用；
- L3：多个规律相互约束形成完整推理链；
- L4：跨情境迁移、一般化、递推、渐近、优化或构造新推理路径。

### 3. 科学论证

定义：运用理由、证据、比较、检验或边界分析来支持、评价、反驳或修正物理结论。

纳入：

- 比较多个模型、条件、方案或临界情形；
- 解释结论为什么成立；
- 用极限、量纲、边界、稳定性、反例或误差阶检验结论；
- 对近似、忽略因素或假设进行辩护。

排除：

- 常规推导本身；
- 只给最终表达式或数值；
- 只按题号分步计算；
- 参考解答用了“证明”二字，但实质只是代数推导。

等级：

- L1：给出支持单一结论的基本理由；
- L2：比较条件、情形或方案；
- L3：系统检验、边界分析或误差/假设辩护；
- L4：对模型、条件或结论进行抽象层面的普遍论证或拓展。

### 4. 质疑创新

定义：在题目要求下识别或挑战假设、比较替代解释、修正模型或提出受证据约束的新方案。

纳入：

- 题目明确要求指出、评价或处理假设；
- 需要比较替代模型或解释；
- 需要识别近似失效并修正模型；
- 需要开放设计方案并论证。

排除：

- 背景前沿但解法固定；
- 解法陌生但题目未要求质疑假设；
- 研究者可以想到替代方案，但题目未要求；
- 单纯估算或复杂计算。

等级：

- L1：识别题目要求处理的显性假设；
- L2：比较替代解释、模型或方案；
- L3：识别假设失效并修正或拓展模型；
- L4：在开放约束下构造新模型或方案并进行证据约束论证。

## 六、编码记录要求

每条编码至少记录：

- 维度是否出现；
- 出现时的等级；
- 判定证据；
- 与相邻等级的区别；
- 不确定性；
- 是否需要手册修订。

## 七、正式使用前置条件

本草案进入正式编码前必须完成：

1. 高优先级OCR与公式校对；
2. 真实专家审查或导师确认；
3. 至少两名评分者独立试编码；
4. 分歧讨论和手册修订；
5. 一致性检验；
6. 冻结正式版编码手册。
