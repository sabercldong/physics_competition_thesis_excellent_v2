# 理论框架：科学思维维度与认知结构要求

## 1. 理论对象

本研究分析的是试题要求学生完成的认知活动，不直接声称测量学生真实拥有的思维水平。

## 2. 科学思维维度

暂设：

- 模型建构；
- 科学推理；
- 科学论证；
- 质疑创新。

每个维度都必须具备：定义、可观察指标、纳入标准、排除标准、正例、反例和边界案例。

## 3. SOLO的适配

SOLO理论用于描述学习成果的结构复杂性。为避免直接错用，本研究拟使用“SOLO启发的认知结构要求等级”：

- L1 单一要素要求；
- L2 多要素并列要求；
- L3 多要素关联整合要求；
- L4 抽象迁移或拓展要求。

是否保留“前结构”应根据任务分析的理论依据和专家意见决定。对试题任务而言，前结构通常不是合理的要求层级。

## 4. 两层编码

### 层1：维度存在性

判断某小问是否明确要求四类科学思维活动。

### 层2：结构深度

对出现的维度判断其认知结构要求等级。

因此，一道小问可形成例如：

- 模型建构：L3；
- 科学推理：L3；
- 科学论证：L1；
- 质疑创新：未出现。

这比给整题一个模糊总等级更有解释力。

## 5. 不建立无依据总分

除非完成明确的理论论证、专家审查和稳健性分析，否则不将四维度和层级加权为“综合思维难度指数”。
