# G3-04-DRAFT 评分者培训版手册候选稿

更新时间：2026-07-14

> 状态：评分者培训版候选稿。本文用于真实评分者独立试编码前的培训准备，来源于 `analysis_unit_and_coding_definitions_formal_draft.md`、`codebook_v2_formal_draft.csv`、正式空白编码模板和内部复核风险表。本文不代表真实评分者意见、专家审查结论、正式编码结果或一致性检验结果。

## 一、使用目标

本手册候选稿服务三个目标：

1. 让评分者使用同一套分析单位、维度定义和 L1-L4 等级规则；
2. 让每条编码都能写出可追溯证据，而不是只给判断结果；
3. 让分歧能被记录、分类和修订手册，而不是为了提高一致率提前讨论答案。

## 二、评分者必须阅读的材料

正式试编码前，评分者应按顺序阅读：

1. `04_framework/analysis_unit_and_coding_definitions_formal_draft.md`
2. `04_framework/codebook_v2_formal_draft.csv`
3. `04_framework/evidence_note_and_disagreement_protocol_formal_draft.md`
4. `04_framework/boundary_case_bank_formal_draft.csv`
5. 对应样本小问的 `03_corpus/item_texts/` 整理文本
6. 必要时对照原始 PDF 和参考解答页

若评分者发现题干、公式、题图或小问边界存在疑点，应先标为“待核实”，不得凭经验补全题意。

## 三、独立编码流程

### 3.1 编码前检查

每名评分者独立确认：

- 是否知道本轮使用的手册版本；
- 是否取得空白模板；
- 是否知道不能查看另一评分者结果；
- 是否知道不能复制 Codex 内部试编码；
- 是否知道证据必须来自题干、参考解答或题图；
- 是否知道 OCR、公式、题图或页码疑点应标为待核实。

### 3.2 单条记录判断顺序

每条 `item_id + dimension` 记录按以下顺序判断：

1. 确认分析单位是否清楚；
2. 阅读该小问题干、图表和参考解答；
3. 判断该维度是否出现；
4. 若出现，判断 L1-L4 等级；
5. 写出可定位证据；
6. 写出把握度；
7. 如有疑点，在 `notes` 中说明。

不要先看等级，再倒找证据。若找不到可定位证据，应降低把握度或标为“待核实”。

## 四、字段填写规则

| 字段 | 填写规则 | 常见错误 |
|---|---|---|
| `present` | 只能填“是”或“否”。 | 用“可能”“部分出现”等模糊词。 |
| `level` | 若出现，填 L1-L4；若未出现，填“未出现”。 | `present=否` 但仍填 L2 或 L3。 |
| `evidence` | 写明证据来源、位置和依据，如题干条件、图示、参考解答步骤。 | 只写“需要推理”“较复杂”。 |
| `confidence` | 填“高”“中”“低”。 | 把把握度当作题目难度。 |
| `coder_id` | 使用评分者匿名编号。 | 写真实姓名或留空。 |
| `manual_version` | 填本轮手册版本。 | 使用“待正式冻结”以外的自造版本名。 |
| `notes` | 写待核实、边界疑点、相邻等级疑点。 | 写正式结论或替另一评分者解释。 |

## 五、维度判断提醒

### 5.1 模型建构

优先看题目是否要求确定研究对象、系统边界、理想化假设或模型迁移。不要因为有图、变量多或背景陌生就自动判为模型建构高等级。

### 5.2 科学推理

优先看条件到结论之间是否形成物理逻辑链。不要把纯代数复杂度当作科学推理等级。

### 5.3 科学论证

优先看题目是否要求理由、比较、检验、边界说明或假设辩护。常规推导即使很长，也不自动构成科学论证。

### 5.4 质疑创新

优先看题目是否明确要求处理假设、比较替代方案、修正模型或构造开放方案。研究者自己想到的替代解法不能触发该维度。

## 六、L1-L4 判断提醒

| 等级 | 评分者要问自己的问题 | 不足以触发的情况 |
|---|---|---|
| L1 | 是否主要依赖一个关系、对象、理由或显性假设？ | 题目难但结构单一。 |
| L2 | 是否并列使用多个关系、条件、情形或方案？ | 只是公式多。 |
| L3 | 多个规律、过程或条件是否相互约束并形成整体结构？ | 只是顺序计算。 |
| L4 | 是否存在迁移、一般化、递推、渐近、优化、模型修正、开放构造或抽象论证？ | 只是计算很长、背景前沿或符号陌生。 |

L4 是高风险等级。凡判 L4，必须在证据中写明触发 L4 的原始题干或参考解答依据。

## 七、边界案例训练方式

`boundary_case_bank_formal_draft.csv` 不是标准答案库，而是训练用风险清单。评分者训练时应：

1. 先独立判断这些案例；
2. 标出自己认为最关键的证据；
3. 写出相邻等级边界；
4. 记录是否受 OCR、公式或图像未销项影响；
5. 培训讨论只讨论规则和证据，不把讨论结果写成正式编码。

## 八、分歧处理原则

分歧处理顺序为：

1. 先查材料是否可靠；
2. 再查分析单位是否一致；
3. 再查维度是否出现；
4. 再查等级边界；
5. 最后决定是裁决、保留待核实，还是修订手册。

若分歧源于手册定义不清，应优先修订手册，而不是强行让一方改成另一方的结果。

## 九、停止条件

出现以下情况时，评分者不应继续强行编码，应标为“待核实”并记录：

- 题干 OCR 明显可能改变物理条件；
- 公式、上下标、单位或符号无法确认；
- 题图裁边影响理解；
- 小问边界和分析单位不清；
- 参考解答页码或步骤无法定位；
- 手册定义无法区分相邻等级。

## 十、正式化前仍需完成

本候选稿进入正式手册前仍需：

- 人工校对关键题干、公式和图像；
- 真实评分者独立试编码；
- 分歧记录和手册修订；
- 一致性计算和逐变量报告；
- 导师或项目负责人确认最终版本。
