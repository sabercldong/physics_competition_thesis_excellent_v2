# 全国中学生物理竞赛复赛理论试题科学思维编码手册 V3

版本日期：2026-07-29

版本状态：重建试编码版

适用语料：第35—42届全国中学生物理竞赛复赛理论试题的219个分析单元

## 一、版本用途

V3用于重新判定试题要求的科学思维活动。旧版编码及其统计结果只作为历史记录，不得复制到V3编码表，也不得作为评分者判断依据。V3通过试编码、边界案例讨论和一致性检查后，才能生成论文中的正式统计结果。

本手册分析的是试题任务要求，不是学生实际表现，不评价试题难度、区分度、知识点数量或解答篇幅。

## 二、分析单位

1. 默认以能够独立作答、具有明确输出要求的最小小问为一个分析单元。
2. 同一小问包含多个连续步骤，但不能在题面上独立作答时，不再人为拆分。
3. 后续小问明确调用前问结果时，可继承该结果，不自动继承前问的思维维度和等级。
4. 共享题干、图、装置和参数只提供情境。只有小问必须处理其中的信息时，才可作为该小问的编码证据。
5. 参考解答用于确认完成任务所需的最低认知活动，不得仅凭解答写得复杂而提高等级。

## 三、逐条判定流程

每个分析单元分别对四个维度执行以下步骤：

1. **确定输出**：用一个动宾短语写明该小问要求得到什么。
2. **提取证据**：分别摘录可逐字定位的题干原文和参考解答关键步骤。
3. **概括必要活动**：写成“对什么对象，进行什么认知操作，形成什么关系或结论”。
4. **判断存在性**：检查该活动是否达到相应维度的最低门槛。
5. **执行反事实检查**：若删除拟判定的活动，任务是否仍可通过直接读数、照抄公式、机械代入或纯代数运算完成。若可以，该维度通常判为“否”。
6. **确定最低充分等级**：只选择足以解释任务要求的最低等级。
7. **排除相邻等级**：说明为什么不取更低一级；L2以上还须说明为什么尚未达到更高一级。
8. **记录置信度**：高、中、低。证据缺失、文字损坏或边界无法判定时标记“待裁决”，不得强行填入正式标签。

题干关键词、知识背景、公式数量、页数、分值和经验难度均不能单独触发维度或等级。

## 四、四维度操作性定义

### 4.1 模型建构

模型建构是把物理情境转化为可处理的对象、状态、相互作用、变量、约束和关系结构，并据此选择、建立、整合、修正或迁移模型。

#### 存在门槛

至少满足下列一项，并能在题干或参考解答中定位：

1. 从情境中确定研究对象、系统边界、理想化条件或关键状态；
2. 将文字、图像或装置转化为受力关系、几何关系、等效结构、状态关系或动力学方程；
3. 协调多个对象、过程、参考系或约束，建立可求解的统一表示；
4. 根据新条件修正、迁移、推广或自行构造模型。

#### 排除规则

以下情况本身不足以判为模型建构：

1. 题干已经给出完整模型和公式，作答者只需代入；
2. 只识别一个物理量、单位或现成公式，未完成情境到模型的映射；
3. 纯代数整理、求导、积分或数值计算；
4. 仅因题目属于陌生、前沿或竞赛情境；
5. 参考解答自行补写了复杂模型，但题面任务并不要求作答者完成该建模活动。

#### 等级

| 等级 | 判定标准 |
|---|---|
| L1 | 识别一个标准模型，并完成至少一个关键对象、变量或条件到模型关系的映射。 |
| L2 | 并列建立或协调两个以上对象、关系或局部子模型，但它们之间的相互约束较弱。 |
| L3 | 将多个阶段、参考系、边界条件、对象或子模型整合为相互约束的统一模型。 |
| L4 | 在信息不完全或新约束下修正、迁移、一般化或自主构造模型，并说明构造依据。 |

### 4.2 科学推理

科学推理是依据条件、规律、数据或中间结果，通过逻辑或定量关系得到新结论的过程。

#### 存在门槛

至少需要一个有物理意义的推断步骤，使条件或中间结果转化为新的物理结论。必须写明“依据什么关系，从什么条件推出什么结论”。

#### 排除规则

以下情况本身不足以判为科学推理：

1. 从题干直接读数、抄写定义或复述已给结论；
2. 将数值机械代入题干已给出的完整公式；
3. 不改变物理含义的符号抄写、单位换算或代数化简；
4. 仅因解答出现多个公式、求导或积分；
5. 只有计算过程而无法说明条件与物理结论之间的关系。

#### 等级

| 等级 | 判定标准 |
|---|---|
| L1 | 依据一个主要物理关系完成一个直接推断。 |
| L2 | 串联或并列使用两个以上可区分的关系，形成局部推理链。 |
| L3 | 多个规律、条件或阶段相互约束，并包含情形分类、临界判断、反馈关系、优化或完整因果链。 |
| L4 | 对推理结构进行迁移、一般化或重新构造，得到超出当前特例的规则、方法或新路径。 |

递推、积分、微分方程和极值计算只说明可能存在复杂结构，不能单独触发L3或L4。

### 4.3 科学论证

科学论证是围绕一个需要成立、比较或检验的主张，组织证据和理由，说明该主张为什么成立、在何种条件下成立或何时失效。

#### 存在门槛

编码证据中必须同时能够识别：

1. 一个待支持、比较或检验的主张；
2. 至少一条与该主张形成支持关系的证据或理由。

#### 排除规则

以下情况本身不足以判为科学论证：

1. 仅列方程并求得数值或表达式；
2. 参考解答给出推导，但题面只要求“求”且无需解释结论为何成立；
3. 题干出现“证明”字样，但实际任务仅为恒等变形；
4. 多步骤计算、结果正确性或高难度；
5. 只有结论，没有证据与理由的连接。

#### 等级

| 等级 | 判定标准 |
|---|---|
| L1 | 用一条主要证据或理由支持一个明确主张。 |
| L2 | 比较两个以上条件、情形、解释或方案，并说明结论差异。 |
| L3 | 系统检验主张，处理边界、误差、反例、适用条件或关键假设。 |
| L4 | 建立可迁移的一般论证准则，或对模型和结论进行抽象层面的系统辩护。 |

### 4.4 质疑创新

质疑创新是主动识别既有假设、模型、解释或方案的局限，并提出替代、修正、拓展或开放构造。

#### 存在门槛

题面必须要求作答者至少完成下列活动之一：

1. 识别或评价一个假设、模型、方法或结论的局限；
2. 比较具有实质差异的替代解释、模型或方案；
3. 在原模型失效或条件改变时提出修正或拓展；
4. 在不唯一约束下设计新方案、构造新模型，并以证据说明选择。

#### 排除规则

以下情况不得自动判为质疑创新：

1. 题干向作答者直接给出“假设”“近似”“模型”；
2. 在唯一标准路径中使用题目规定的理想化条件；
3. 求极值、求参数、分类讨论或完成复杂推导；
4. 使用新颖背景、前沿知识或非常规公式；
5. 参考解答给出一种巧妙做法，但题面未要求作答者评价、替代、修正或设计；
6. 有唯一标准答案的封闭计算任务，除非题面明确要求产生并论证新的方案或模型。

#### 等级

| 等级 | 判定标准 |
|---|---|
| L1 | 识别并说明一个假设、方法或结论的具体局限。 |
| L2 | 比较两个以上实质不同的解释、模型或方案，或在明确约束下提出替代方案。 |
| L3 | 针对失效条件修正、拓展模型或改进方案，并说明修正依据。 |
| L4 | 在开放约束下自主构造新模型或方案，处理权衡，并用证据进行系统论证或一般化。 |

L4属于极少数高风险标签。没有“开放构造、证据约束、非唯一选择”三项证据，不得判为L4。

## 五、相邻维度区分

| 容易混淆的维度 | 区分问题 |
|---|---|
| 模型建构与科学推理 | 是否先把情境组织为对象、变量、约束和关系结构？这是模型建构。是否在既有结构上由条件推出新结论？这是科学推理。两者可同时出现，但不能相互代替。 |
| 科学推理与科学论证 | 推导一个结果主要是推理；围绕“为什么该结论可信或在何种条件成立”组织主张、证据和理由才是论证。 |
| 模型建构与质疑创新 | 建立标准模型可以是模型建构；只有评价其局限、提出替代或修正，才进入质疑创新。 |
| 科学论证与质疑创新 | 比较或检验已有主张可以是论证；主动提出替代、修正或新方案才进入质疑创新。 |

## 六、证据字段最低要求

每条编码必须填写：

1. `item_id`与维度；
2. 题干逐字引文及页码、小问定位；
3. 参考解答逐字引文及页码、式号或步骤定位；
4. 任务要求的输出；
5. 必要认知活动；
6. 是否出现及等级；
7. 存在或排除理由；
8. 相邻等级排除理由；
9. 置信度、评分者代号和日期。

判为“否”时，等级必须为“未出现”，并填写排除理由。判为“是”时，等级必须为L1—L4，且至少有一条题干证据和一条用于确认任务结构的解答证据。无法逐字定位或证据互相冲突时，状态为“待裁决”。

## 七、质量门槛

1. 旧标签不得出现在评分者空白表中。
2. 先完成不少于20个分析单元、覆盖四个维度和全部等级边界的试编码。
3. 所有L4、所有“质疑创新=是”、所有“科学论证=是”和所有低置信度记录进入强制复核。
4. 若某维度出现率达到95%以上或5%以下，必须进行饱和或稀疏性专项复审。
5. 一致性指标只能描述文件级编码结果；评分者身份独立性另行记录，不由数据文件自动证明。
6. 正式统计只能读取通过字段校验、边界复核和裁决后的唯一版本。

## 八、禁止做法

1. 根据关键词批量赋值；
2. 按整道大题给所有小问复制相同维度；
3. 根据知识模块、年份、分值或答案长度推断等级；
4. 为获得更“好看”的分布而调整标签；
5. 用旧统计反向约束新编码；
6. 把智能体预判、程序筛查或历史裁决冒充人工实质判断。
