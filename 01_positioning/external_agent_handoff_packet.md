# 外部协作者真实材料交接包

更新时间：2026-07-22

## 用途

本包供具有真实材料、真实阅读权限、真实校对/评分资格或真实课堂材料的外部协作者领取任务。所有任务都要求提交可追溯的真实副本、匿名编码或实际日期；没有真实材料时，请保持“未完成”，不要模拟填写。

## 共同规则

1. 先阅读对应的起始材料，再领取任务。
2. 真实副本首次到达时只能进入接收登记和结构检查；不得直接修改论文、主张矩阵、正式编码或统计表。
3. 校对任务、评分者编码、文献阅读、教学证据和学校规范确认分别处理，彼此不能替代。
4. 不得编造校对决定、专家/导师意见、页码、问卷、访谈、课堂记录、学生作品、统计或显著性结论。
5. 正式结果必须等待人工校对、真实A/B编码、一致性、裁决和`final_coding.csv`全部真实完成。

## 可领取任务

见 `01_positioning/external_agent_handoff_packet_v1.csv`。当前8项均为待真实材料或待真实回填，均不放行论文正式结果。

## 优先顺序

1. A/B/C/D人工校对回填：解决正式语料输入门槛。
2. SOLO全文：解决理论边界的页码级依据。
3. 两名独立评分者：必须在正式输入冻结后启动。
4. 教师/课堂材料与学校规范：决定第五章实证范围和最终写作格式。

## 接收后流程

收到任何真实副本后，按 `03_corpus/no_return_real_return_trigger_map.md` 的TRM-02开始；正式结果出口在TRM-08之后，不能跳步。
