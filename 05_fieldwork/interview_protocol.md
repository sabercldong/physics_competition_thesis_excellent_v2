# 半结构访谈提纲

## 访谈目标

- 理解竞赛教师如何识别试题思维要求；
- 了解学生常见思维障碍；
- 解释教学策略的现实可行性；
- 为教学转化矩阵提供真实情境证据。

## 核心问题

1. 你如何判断一道复赛题真正难在哪里？
2. 学生在从题目到模型的过程中最常卡在哪一步？
3. 你如何让学生解释推理而不是只给答案？
4. 你是否使用极限、量纲、反例或不同解法检验结论？
5. 哪些教学活动最能促进迁移，哪些容易制造“会做不会变”？
6. 你如何处理班级内基础差异？
7. 对本研究提出的教学设计模式，你认为哪些可行，哪些不现实？

## 追问原则

- 要求具体课堂案例；
- 追问学生原话或作品；
- 区分理想做法与实际做法；
- 追问限制条件；
- 不诱导受访者认同研究者观点。
