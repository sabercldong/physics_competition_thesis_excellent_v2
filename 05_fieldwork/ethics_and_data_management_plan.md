# G0-05 伦理与数据管理执行方案

更新时间：2026-07-14

## 一、本方案的作用

本方案规定后续教师问卷、访谈、专家咨询、课堂设计、学生作品和前后表现任务的采集、匿名化、保存、分析和正文使用门槛。当前项目尚无真实问卷回收、访谈转写、课堂日志、学生作品或前后测原始数据，因此本方案只建立执行条件，不声称已经完成任何人类参与者研究。

## 三、路线分流

### 3.1 教师访谈优先

适用条件：

- 能联系少量竞赛教师；
- 目标是解释教学困难、策略可行性和任务设计条件；
- 不追求总体比例推断。

最低证据包：

- `consent_log.csv`
- `interview_metadata.csv`
- 匿名转写或匿名摘录
- `transcript_coding.csv`
- 主题分析说明

### 3.2 问卷加访谈

适用条件：

- 能获得足够且来源清楚的教师样本；
- 问卷已经过预测试和变量说明修订；
- 能报告样本范围、缺失值和分析方法。

最低证据包：

- 问卷版本记录；
- `survey_codebook.csv`
- `survey_responses.csv` 或匿名派生表；
- 清洗日志；
- 描述统计脚本；
- 访谈或开放题用于解释结果。

### 3.3 专家咨询或教学案例评审

适用条件：

- 无法开展大规模教师调查；
- 只需要对教学转化方案、任务和量规做可行性评审。

最低证据包：

- 专家背景标签；
- 同意记录；
- 评审表；
- 意见汇总；
- 修订日志。

### 3.4 课堂设计型研究

适用条件：

- 有真实课堂入口；
- 可保存教案、实施记录、学生作品和评分；
- 至少能完成一轮设计、实施、反思和修订。

最低证据包：

- 课堂许可和同意记录；
- 教案与任务材料；
- `fidelity_log.csv`
- `student_artifact_index.csv`
- 量规和评分记录；
- 教师日志；
- 修订依据。

### 3.5 准实验或前后测

当前不推荐作为默认路线。若保留，必须先具备：

- 伦理或学校许可；
- 样本招募和分组记录；
- 测量工具、评分标准和信效度证据；
- 原始前后测数据；
- 缺失值处理；
- 统计脚本；
- 效应量和置信区间。

没有这些材料时，不得写“显著提升”“验证有效”“实验组优于对照组”。

## 四、采集流程

1. 决定路线和样本范围。
2. 修订知情说明、访谈提纲、问卷或课堂任务。
3. 进行预测试或小范围试访。
4. 为参与者生成匿名编号。
5. 记录同意信息，不把签名原件放入公开仓库。
6. 收集原始材料并保存到私有位置。
7. 生成去标识化副本。
8. 填写元数据表和清洗日志。
9. 再进入编码、统计或主题分析。
10. 把正文主张写入主张证据矩阵。

## 五、匿名编号规则

| 对象 | 编号格式 | 示例 |
|---|---|---|
| 教师 | T加三位数字 | T001 |
| 专家 | E加三位数字 | E001 |
| 学生 | S加三位数字 | S001 |
| 班级 | C加三位数字 | C001 |
| 访谈 | INT加三位数字 | INT001 |
| 问卷响应 | SUR加三位数字 | SUR001 |
| 学生作品 | ART加三位数字 | ART001 |
| 课堂课次 | LES加三位数字 | LES001 |

编号和真实身份的对应表属于私有敏感材料，不进入公开Git。

## 七、正文可用性判定

| 想写的正文表述 | 必须具备 | 当前判定 |
|---|---|---|
| 教师普遍采用某类教学方式 | 样本清楚的问卷数据和分析脚本 | 不能写 |
| 教师认为某教学策略可行 | 匿名访谈或专家评审记录 | 待收集后可写 |
| 学生在某维度存在困难 | 学生作品、教师访谈或课堂记录 | 不能凭试题直接写 |
| 教学设计在课堂中暴露了某问题 | 课堂实施记录和教师日志 | 待收集后可写 |
| 教学策略显著提升成绩或思维 | 前后测原始数据、测量工具、统计脚本 | 当前不能写 |
| 策略具有普遍推广价值 | 多场景证据和边界分析 | 当前不能写 |

## 八、质量检查

每次采集后检查：

- 是否有同意记录；
- 是否存在真实姓名、联系方式或精确学校名称；
- 是否有匿名副本；
- 是否记录采集日期、采集者和版本；
- 是否保留清洗日志；
- 是否把原始材料和派生材料分开；
- 是否能从正文主张回到数据行或摘录编号；
- 是否避免把教师意见写成客观命题事实；
- 是否避免把短期表现写成长期科学思维提升。

## 九、暂不执行事项

当前不执行：

- 真实招募；
- 问卷发放；
- 访谈；
- 课堂实施；
- 学生作品收集；
- 前后测；
- 专家意见回收；
- 任何显著性检验。

这些事项需在路线、学校要求和真实数据入口明确后另立任务。
